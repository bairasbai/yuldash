# Юлдаш Mobile

Flutter-приложение для iOS и Android.

> ⚠️ **Заброшено, не трогать.** Рабочий клиент — `android/` (Kotlin + Jetpack Compose); веб-версия — `webapp/`. Эта папка — первый прототип на Flutter; по правилам проекта не развивается и в проде не используется. См. `CLAUDE.md` §0 и §11. Экспериментальный iOS-эксперимент на Compose Multiplatform — `experiments/cmp-ios-poc/`.

## Статус (прототипа)

Создан первый исходный слой приложения:

- вход по телефону;
- главный экран с картой-прототипом;
- список поездок;
- создание поездки;
- профиль;
- добровольная поддержка;
- платное поднятие объявления заложено в UX;
- ARB-файлы для русского и башкирского языков.

## Запуск

На этой машине команда `flutter --version` не найдена в PATH, поэтому локальная сборка здесь не проверена.

После установки Flutter SDK:

```powershell
cd mobile
flutter create .
flutter pub get
flutter run
```

Команда `flutter create .` нужна, чтобы сгенерировать платформенные папки `android/` и `ios/`.
