# Пока рассветает

Сайт с письмами до встречи. Каждое утро в 8:00 по Уфе телеграм-бот зовёт
Илизу на сайт, там её ждёт конверт с письмом. Небо на сайте светлеет с
каждым днём: в начале ночь, в день прилёта — рассвет.

---

## Что где лежит

| Что менять | Файл |
|---|---|
| Тексты писем | `data/letters.ts` |
| Дата встречи, имена, города | `lib/config.ts` |
| Хроника «мы» | `data/timeline.ts` |
| Письмо «когда грустно» | `data/special.ts` |
| Наши песни | `data/playlist.ts` |
| Вопросы дня | `data/questions.ts` |
| Цвета неба | `lib/sky.ts` |

## Страницы

- `/` — отсчёт и сегодняшний конверт
- `/letters` — архив, будущие письма заперты
- `/us` — часы, погода, карта Москва—Уфа, хроника
- `/together` — «думаю о тебе» и конверт «когда грустно»
- `/him` — служебная страница Байраса: что написано, что нет, проверка бота
- `/gate` — вход по кодовому слову

## Как выложить сайт (делается один раз)

### 1. Vercel

Зайти на vercel.com, войти через GitHub, нажать **Add New → Project**,
выбрать этот репозиторий, нажать Deploy. Через минуту сайт живой на
адресе вида `dawn-letters.vercel.app`.

### 2. Переменные

В Vercel: **Settings → Environment Variables**. Добавить всё из
`.env.example` со своими значениями:

| Имя | Что это |
|---|---|
| `ACCESS_CODE_HER` | код Илизы на входе |
| `ACCESS_CODE_HIM` | твой код, другой |
| `SESSION_SECRET` | длинная случайная строка |
| `TELEGRAM_BOT_TOKEN` | выдаёт @BotFather |
| `TELEGRAM_CHAT_ID_HER` | её номер чата |
| `TELEGRAM_CHAT_ID_HIM` | твой номер чата |
| `SITE_URL` | адрес сайта, например `https://твойдомен.ру` |
| `CRON_SECRET` | длинная случайная строка |
| `DATABASE_URL` | хранилище, см. шаг 5 |

Точки, пробелы и регистр в кодах не важны: `02.07.2026` и `02072026` —
одно и то же.

### 3. Бот

1. В телеграме написать **@BotFather**, отправить `/newbot`, придумать имя.
   Он выдаст токен — это `TELEGRAM_BOT_TOKEN`.
2. Написать своему боту «привет» со своего телефона.
3. Дать ссылку на бота Илизе, чтобы она нажала «Начать». **Без этого бот
   не имеет права ей писать** — так устроен телеграм.
4. Открыть в браузере `https://твойдомен.ру/api/telegram/chats?key=CRON_SECRET`
   — там будут оба номера чатов. Вписать их в переменные.

### 4. Домен из timeweb

В Vercel: **Settings → Domains**, добавить свой домен. Vercel покажет,
какие записи прописать. В личном кабинете timeweb открыть управление DNS
домена и добавить то, что он показал — обычно это:

- запись **A** для `@` → `76.76.21.21`
- запись **CNAME** для `www` → `cname.vercel-dns.com`

Домен подхватится за 10–30 минут.

### 5. Хранилище

Нужно там, где сайт должен что-то помнить: список «что сделаем в Уфе»,
настроение, вопрос дня, ответы на письма, капсула. **Письма, отсчёт
и утренняя доставка от него не зависят** — без базы они работают,
просто эти разделы будут пустыми.

В Vercel: **Storage → Create Database → Neon** (бесплатный тариф),
дальше **Connect Project**. Переменная `DATABASE_URL` подставится сама.
Таблицы сайт создаст при первом заходе, делать ничего не нужно.

### 6. Проверить

Зайти на сайт своим кодом, открыть `/him`, нажать «проверить бота» —
в телеграм должно прийти сообщение. Там же видно, подключено ли
хранилище.

## Как что-то поменять потом

**Написать письмо.** Открыть `data/letters.ts`, найти нужный номер,
вписать текст абзацами и поставить `ready: true`. Сохранить, закоммитить —
Vercel сам пересоберёт сайт за минуту.

**Сдвинуть дату встречи.** В `lib/config.ts` поменять `meetDate`.
Количество писем и отсчёт пересчитаются сами.

**Посмотреть, как сайт выглядит в другой день.** Только на своём
компьютере: `DEBUG_TODAY=2026-08-19 npm run dev`. На рабочем сайте это
не действует.

## Запуск у себя

```bash
npm install
cp .env.example .env.local   # вписать свои значения
npm run dev
```

Сайт откроется на `http://localhost:3000`.
