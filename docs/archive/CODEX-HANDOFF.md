## Правила работы
- Каждая задача — своя ветка и свой git worktree; main не трогать напрямую. Влить в main можно только когда ВСЕ проверки CI зелёные.
- Перед вливанием подтяни свежий origin/main в ветку. Если после этого изменился код — дождись новой проверки CI.
- GitHub — не частить (аккаунт уже блокировали): никакого `gh run watch`, никаких циклов с `gh`, запросы по одному, CI смотреть не чаще раза в 2–3 минуты. Отказ стража ~/.claude/hooks/github-api-guard.js — стоп, не обходить.
- Файлы local.properties, google-services.json, keystore.properties, *.jks не читать и не создавать. Имя бота уже подставляется по умолчанию.
- Ноутбук 16 ГБ: одна Gradle-сборка или эмулятор за раз. Перед Gradle нужно ≥3,5 ГБ свободной памяти, перед эмулятором ≥5 ГБ, и чужих процессов java не должно быть. Всё, что запустил (эмулятор, сервер, Postgres, Gradle), останови сам.
- Сборка: JAVA_HOME='C:\Program Files\Android\Android Studio\jbr', ANDROID_HOME=%LOCALAPPDATA%\Android\Sdk, `gradlew.bat --no-daemon -Dorg.gradle.jvmargs=-Xmx2g`. Python бэкенда — C:\Users\Bayra\Yuldash\backend\.venv.
- Проверки как в CI: Android — полный `:app:testDebugUnitTest` + `:app:assembleDebug`; бэкенд — `ruff check app/ --select F` + `pytest tests/ --cov=app --cov-fail-under=85`; сайт — команды check и build из webapp/package.json.
