## 3. ⚠️ Ловушка среды: сломанная командная строка

В конце сессии 29.08 инструмент Bash начал падать на **любой** команде, включая `true`:

```
/usr/bin/bash: -c: line 71: unexpected EOF while looking for matching `''
```

Ошибка приходит из обёртки, которую подставляет сам инструмент, ДО пользовательской команды.
Признаки нарастали постепенно: сначала падали отдельные команды (`git`, `tail`, `sed`),
потом всё. Лечится перезапуском сессии.

Пока это происходит: тесты не гоняются, `git` не работает, файлы удалять нечем. **Волну
в таком состоянии закрывать нельзя** — правило «не помечать готово без зелёного запуска».

**Обход, которым в итоге всё и доделали:** MCP-инструмент `mcp__ruflo__terminal_execute` —
он запускает команды мимо сломанной обёртки Bash. Там **cmd.exe, а не bash**, поэтому:

* `cd /d "C:\путь"` вместо `cd`, `del /q файл` вместо `rm -f`;
* `set PYTHONIOENCODING=utf-8 &&` перед python, иначе кириллица в выводе падает на cp1251;
* нет `head`, `tail`, `grep` — длинный вывод режь питоном.

Побочные приёмы, которые работали, пока шелл был жив только наполовину:

* длинный python-скрипт писать **инструментом Write**, а не heredoc'ом (heredoc обрезается);
* запускать скрипт коротким относительным путём из `backend/`, а не абсолютным;
* `Grep`/`Glob`/`Read` вместо `grep`/`ls`/`cat` — они идут мимо шелла.

## 5. Волна 210 — угол найден, проба НЕ запускалась

**Дверь:** `GET /r/{ride_id}` в `app/routers/share.py` — публичная страница поездки,
та самая, что уходит ссылкой в мессенджер и разворачивается карточкой.

```python
ride = session.get(Ride, ride_id)
if not ride or not _shareable(ride, session):      # результат ВЫБРОШЕН
    raise herr(404, ...)
return HTMLResponse(_render_html(_preview_dict(ride, session), lang))
#                                ^^^^ исходная поездка, не обезличенная копия
```

`_shareable` возвращает не «да/нет», а саму обезличенную копию: `visible_rides` для анонима
стирает связку с клиникой (`partner_id=None`, `category=regular`). Соседняя дверь
`GET /r/{id}/preview` строит витрину по копии (`показываемая`) — её починили волной 160.
HTML-страница осталась на исходной поездке.

**Дыра латентная.** Сегодня наружу текстом не выходит по случайности: в `_CATEGORY` нет ключа
`hospital`, подпись падает в запасную «Поездка». Откроется в день, когда кто-нибудь добавит
строку «Больница / Дауахана» — правку на одну строку, выглядящую как улучшение. Тогда
карточка в семейном чате начнёт печатать «БОЛЬНИЦА» рядом с именем водителя, датой
и маршрутом.

Починка — одно слово: строить страницу по копии, как соседняя дверь.

**Проба (написана, НЕ запущена — шелл умер раньше).** Ловит на входе в отрисовку, а не
по готовому HTML: иначе тест проверяет словарь `_CATEGORY`, а не дверь.

```python
def test_public_page_is_built_from_the_anonymised_copy(client, user_factory, monkeypatch):
    from app.routers import share

    водитель = user_factory("КлиникаВодитель", role=UserRole.driver)
    with Session(engine) as s:
        поездка = Ride(driver_id=водитель["id"], from_city="Баймак", to_city="Уфа",
                       from_lat=52.59, from_lng=58.31, to_lat=54.73, to_lng=55.95,
                       depart_at=utcnow() + timedelta(days=1), price=500,
                       seats_total=3, seats_left=3, status=RideStatus.active,
                       category=RideCategory.hospital)
        s.add(поездка)
        s.commit()
        s.refresh(поездка)

    monkeypatch.setitem(share._CATEGORY, "hospital", ("Больница", "Дауахана"))
    страница = client.get(f"/r/{rid}").text

    assert "Больница" not in страница and "Дауахана" not in страница, (
        "публичная ссылка на поездку раскрыла анониму связку с клиникой"
    )
```

Проба не проверена запуском — начинать надо с того, что она **красная**. Если зелёная,

# ⚠️ Счётчик смены обнуляется в местную полночь — вопрос на волну 210 (2026-08-29)

Всплыло при слиянии: их новый тест про общую усталость (такси + доставка) покраснел
не от кода, а от часа запуска. Причина — «рабочее время за СЕГОДНЯ» считается по местному
дню (Уфа = UTC+5), и отрезок работы до полуночи в сегодняшний счётчик не попадает.

Сам тест починен: он теперь строит отрезки от полудня, а не от текущего часа, — иначе
краснел бы каждую ночь сам по себе, без единой правки в коде. Поведение продукта я НЕ менял.

**Что осталось вопросом.** Восьмичасовой лимит смены сбрасывается в полночь. Водитель,
который сел за руль в 20:00 и работает без перерыва, в 00:00 получает новые восемь часов —
хотя за рулём он уже четыре. Ночная трасса Сибай–Акъяр в 03:00 — это ровно тот случай,
ради которого лимит и заводили. Возможно, недельный лимит в сорок часов это частично
ловит, но проверять надо отдельно.

Это не поломка, а вопрос к решению: «смена = календарный день» может быть осознанным
упрощением их ветки. Разбирать — отдельной волной, с пробой, а не заодно со слиянием.
