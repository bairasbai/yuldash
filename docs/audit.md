Модерация — `POST /admin/drivers/{id}/moderate`. Бэкенд задеплоен. *(Ниже — исходный текст аудита.)*
   Документы захардкожены («Права: Загружено», «Фото авто: Требуется»), данные авто захардкожены (Kia Rio, белый, 4 места), строки документов **не нажимаются** (нельзя загрузить файл), кнопка «Отправить на проверку» лишь ставит локальный флаг `sent=true`.    По всему коду нет `ACTION_DIAL`/`tel:`. «Помощь звонком» (`CallbackHelpScreen` 5124) **сама пишет**: «в прототипе локально, в реальном уйдёт оператору». CTA рекламы «Позвонить» (стр. 732) тоже **не звонит**.

4. **Клик по рекламе (`trackAdClick` 977) — только Toast + счётчик.** [Точно]
   Нажатие на рекламную карточку показывает всплывашку «Заголовок: Кнопка» и увеличивает локальный счётчик. Не открывает телефон партнёра, сайт или точку на карте. CTA «пустой».

5. **Кабинет рекламы (`AdsCabinetScreen` 5613) — прототип.** [Вероятно]

- **Композер в инбоксе шлёт сообщение в `latestBookingId`** (последнюю бронь), а не в открытый диалог (4255). Логически странно. [Точно]
- **Голосовая/пассажирская заявка создаёт `LocalRequest`** (в памяти) — голос грузится на сервер (`uploadVoice`), но сама заявка, похоже, **не становится серверной поездкой-заявкой** (4753, 4773). [Проверить]

- **Маршрут на карте — прямая линия**, не по дорогам (нужен `-full` SDK + Router). [Точно, известно]

## ➕ Что упущено в продукте (рекомендация дизайнера, не факт)
Премиум «между своими» = доверие + контроль + комфорт. Сильнейшие пробелы против BlaBlaCar/inDrive:
- **Поездка с животным** (флаг у водителя + фильтр у пассажира).
- **Дети + автокресло/бустер** (по ПДД РФ кресло обязательно для малышей — это и закон, и безопасность).
- **Режим «только женщины»** (водитель-женщина / попутчицы) — мощный дифференциатор «между своими».
- **Багаж / число мест / курение / кондиционер / музыка** — стандартные предпочтения.
- **Посылки-передачки между городами** — отдельный сценарий, большой спрос.
- **Правила отмены + регулярные (повторяющиеся) поездки**.
