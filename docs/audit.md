# 🔍 Честный аудит Юлдаш (по коду)

## 🆕 Полный аудит 2026-06-27 (Opus, 3 параллельных аудитора: бэкенд + Android + инфра/доки)

**Готовность: ~70% к закрытой бете «между своими», ~40% к публичному релизу.** Костяк реально работает на проде (не муляж): вход Telegram, поездки, бронь, чат+WebSocket, карта, SOS, рейтинги, проверка водителя.

### 🔴 Безопасность — критичное
- ✅ **ИСПРАВЛЕНО+ЗАДЕПЛОЕНО:** WebSocket-чат `/ws/bookings/{id}` не проверял участника брони → любой залогиненный читал/писал в ЛЮБОЙ чат. Добавлена проверка пассажир/водитель (проверено: чужой → 403).
- ✅ **ИСПРАВЛЕНО:** `validate_production` теперь требует `TELEGRAM_WEBHOOK_SECRET` при заданном боте (на проде уже задан).
- ✅ **ИСПРАВЛЕНО+ЗАДЕПЛОЕНО 2026-06-27:** фото документов водителя — перенесены в приватную папку, отдаются только админу/владельцу (`/secure/docs/{name}`, auth); `/media/docs`→404, `/secure/docs`→401. Овербукинг — `SELECT … FOR UPDATE` на бронировании. Блокировки — применяются (`_is_blocked` в `/bookings` и `/messages`).
- 🔴 **Осталось (мелочь):** `/auth/verify` (SMS-OTP) — нет лимита попыток (но SMS выключен → не активный путь). `/ads/stats` без авторизации (бизнес-статистика, низкая важность).

### 🟡 Моки / заглушки (главное)
- **Платежи — СБП напрямую Александру (это МОДЕЛЬ, не баг — подтвердил 2026-06-27).** Донат/Boost = перевод по СБП на его номер `+7 (999) 134-82-75`, получатель **Байрас · Сбербанк**. Без мерчанта (нет юр.лица) — осознанный P2P «на доверии». Окно показывает номер+имя+банк+выбор банка. ⚠️ Нюанс: **Boost даёт реальную выгоду, а «Я перевёл» не проверяет оплату** → формально любой жмёт и получает Boost бесплатно. Для беты «между своими» — honor-system ок; на росте нужен либо эквайринг с webhook, либо ручное подтверждение Boost. Донату проверка не нужна (выгоды нет).
- **Push-уведомлений нет** (нет FCM, нет permission). «Уведомления» = pull-список.
- Демо-данные (`Mocks.kt`) — фолбэк при недоступном сервере. Хардкод-личность «Байрас»/рейтинг 5.0 в фолбэках. Инбокс чата при пустоте показывает 3 демо-диалога.
- SMS-вход (мок, заморожен), VK/WhatsApp (501, убраны), модерация водителей (ручная), гео-дистанция (9 городов захардкожены), «помощь звонком» (без номера → локальный флаг).

### 🔴 Функциональные баги
- **Дата поездки теряется при публикации** (`CreateRideScreen.kt:449` всегда шлёт «сейчас+3ч» вместо выбранной).
- **Обработки ошибок/офлайна почти нет** — `onFailure` молча игнорится везде (нарушение CLAUDE.md §4.5). При сбое сети показывает «нет поездок» вместо «нет сети · Повторить».
- Публикация — fire-and-forget без обратной связи (если сервер упал — юзер не узнает).

### ⛔ Блокеры (упираются в юр.лицо/ИП у Александра)
SMS, VK, WhatsApp, нормальные платежи (54-ФЗ), стор-публикация (Google Play аккаунт), юр.тексты (152-ФЗ). **Telegram-вход — обходной путь, физлицу доступен, ВКЛЮЧЁН.** Бэкап ключа подписи `yuldash.jks` (потеря = тупик в Play).

## ➕ Что упущено в продукте (рекомендация дизайнера, не факт)
Премиум «между своими» = доверие + контроль + комфорт. Сильнейшие пробелы против BlaBlaCar/inDrive:
- **Поездка с животным** (флаг у водителя + фильтр у пассажира).
- **Дети + автокресло/бустер** (по ПДД РФ кресло обязательно для малышей — это и закон, и безопасность).
- **Режим «только женщины»** (водитель-женщина / попутчицы) — мощный дифференциатор «между своими».
- **Багаж / число мест / курение / кондиционер / музыка** — стандартные предпочтения.
- **Посылки-передачки между городами** — отдельный сценарий, большой спрос.
- **Правила отмены + регулярные (повторяющиеся) поездки**.
