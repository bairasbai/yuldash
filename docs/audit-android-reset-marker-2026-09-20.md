# Отметка очистки: память и диск — 20.09.2026

Подтверждена следующая ошибка OfflineStoreReset: неудачный commit удаления secure_clear_pending мог убрать отметку из памяти, оставив её на диске. Повторный init того же процесса выбирал secure; новые данные B сохранялись туда. Следующий запуск видел старую отметку на диске и удалял уже новые данные.

RED **3/3**: две проверки очереди (включая отказ восстановления отметки) и паспорт поездки. Тестовая MemoryDiskPreferences хранит память и диск отдельно: failed remove меняет только память; restarted создаёт новый объект из дискового снимка. Это модель отказа записи, не физическое повреждение устройства. Доказательства android-reset-marker-red-20260920.log/XML.

Исправление: незавершённый reset удерживается в слабой карте по объекту preferences до подтверждённого завершения. При неудачном удалении делается попытка восстановить отметку; если и она не подтверждена, повторный init всё равно не доверяет отсутствию отметки в памяти. Доступ к этой карте сериализован; не удерживаются сильные ссылки на старые хранилища.
