# 🤖 Вход через Telegram — первичная настройка и ротация

> Руководство по настройке, а не подтверждение текущего состояния рабочего сервера. Доступность Telegram-входа определяется [available_methods()](../backend/app/login_methods.py#L9) по действующим настройкам; в этой уборке их не читали и сервер не меняли. Нельзя по этому файлу заключать, что Telegram сейчас включён либо выключен.
>
> Токены и секреты не присылать в чат и не коммитить. Их настройка владельцем и изменение сервера — отдельное действие по §8 [AGENTS.md](../AGENTS.md). После настройки нужен реальный вход через интерфейс; создание токена из теста не заменяет этот сценарий.

## Как это работает (просто) — вход по коду, как SMS
1. Пользователь жмёт «Вход через Telegram» → открывается твой бот.
2. Жмёт «Старт» → бот узнаёт, кто это (Telegram сам подтверждает личность) и присылает **6-значный код** в чат.
3. Пользователь вводит код в приложении → вошёл.

Код привязан к конкретной попытке входа (случайный request_id), живёт 5 минут, ≤5 попыток. Эти ограничения в конкретной проверяемой версии подтверждаются тестами и сценарием входа, а не одним наличием настройки.

## Шаг 1. Создать бота
1. Открой Telegram, найди **@BotFather**.
2. Напиши `/newbot`, придумай имя и @username (например `yuldash_bot`).
3. BotFather пришлёт **токен** вида `123456:ABC-DEF...` — скопируй.

## Шаг 2. Прописать токен на сервере
Зайди на сервер и впиши токен в `.env`:
```powershell
ssh root@85.239.52.55
nano /opt/yuldash/.env
```
Добавь две строки (секрет — любая длинная случайная строка, придумай сам):
```
TELEGRAM_BOT_TOKEN=123456:ABC-DEF...        # твой токен от BotFather
TELEGRAM_WEBHOOK_SECRET=придумай_длинный_секрет
```
Сохрани (`Ctrl+O`, `Enter`, `Ctrl+X`) и перезапусти API:
```bash
systemctl restart yuldash-api
```

## Шаг 3. Подключить вебхук (один раз)
Подставь свой токен и тот же секрет, выполни на сервере:
```bash
curl "https://api.telegram.org/bot<ТОКЕН>/setWebhook?url=https://yulbash.ru/telegram/webhook&secret_token=<СЕКРЕТ>"
```
Ответ `{"ok":true,...}` = готово.

## Шаг 4. Прописать имя бота в приложении
Имя бота — не секрет (публичный username), поэтому в `android/app/build.gradle.kts` у него есть
значение по умолчанию `yuldash_sms_bot`: оно задаёт имя для ссылки, а не подтверждает доступность входа.
Если бот другой, задай имя (без «@») одним из способов; порядок — сверху вниз, побеждает первый:
1. `gradlew.bat :app:assembleDebug -PyuldashTelegramBot=другой_бот`
2. переменная окружения `YULDASH_TELEGRAM_BOT=другой_бот`
3. строка `YULDASH_TELEGRAM_BOT=другой_бот` в `android/local.properties` (на ноуте, в git не попадает) — только если этот файл меняет сам владелец; агент его не читает и не переносит.

Пустое имя (`-PyuldashTelegramBot=`) скрывает способ Telegram. Непустое задаёт имя для сборки, но кнопка появляется только если сервер также вернул `telegram` среди доступных способов — [LoginScreen.kt](../android/app/src/main/java/com/yuldash/app/LoginScreen.kt#L629). Если доступных способов вообще нет, экран показывает «Вход временно недоступен» и повтор загрузки. Пересборка сама по себе не доказывает успешный вход: нужен полный сценарий ниже.

## Проверить, что работает
- В приложении «Вход через Telegram» → откроется бот → Старт → придёт **6-значный код** → введи в приложении → вошёл.
- Прямо в боте: открой `t.me/yuldash_sms_bot`, нажми Старт без приложения — бот ответит «Открой приложение Юлдаш…» (это норма, код выдаётся только на запрос из приложения).
- Вебхук жив: `curl "https://api.telegram.org/bot<ТОКЕН>/getWebhookInfo"`.

## Если что-то не так
- Кнопка не приходит → проверь, что вебхук подключён: `curl "https://api.telegram.org/bot<ТОКЕН>/getWebhookInfo"`.
- `url` должен быть `https://yulbash.ru/telegram/webhook`, `pending_update_count` маленький.
