## Шаг 2. На сервере — один раз обновить базу

После вливания в `main` и деплоя бэкенда:
```bash
cd backend
alembic upgrade head
```
Это создаст новые таблицы: купоны/партнёры, промокоды, посылки, курьеры. Цепочка миграций **линейная** (одна за другой) — упадёт только если пропустишь. Проверить: `alembic heads` → должна быть **одна** ревизия `courier_c3`.

## Шаг 3. Включить, что нужно (флаги в `.env` / конфиге)

По умолчанию **всё выключено** — включаешь поэтапно, когда готов:

| Флаг | Где | Что делает |
|---|---|---|
| `TAXI_ENABLED=true` | `.env` | включает такси глобально |
| — | админка → «Таксисты» → города | в каких городах такси доступно |
| `COURIER_ENABLED=true` | `.env` | включает режим курьера |
| `COUPONS_ENABLED=true` | (уже true) | раздел «Скидки по пути» |
| Redis | `.env` (`REDIS_URL`) | **обязателен для такси** (без него такси тихо «выключается») |

Купоны/промокоды/посылки работают **без флагов** (безопасны, денег с людей не берут).

## Шаг 6. Что «на доверии» — помни

Деньги **между людьми напрямую** (нал/СБП), Юлдаш их **не держит**:
- оплата поездок/доставок, штрафы такси, комиссия курьера, подписки партнёров, донаты.
- Ты **вручную подтверждаешь** оплаты в Telegram (бот шлёт кнопки) или в админке.
- Реальный эквайринг/авто-списание/страховка — **следующий уровень** (нужно юр.лицо/ИП + договор с банком). Сейчас честно написано пользователям, что деньги напрямую.
