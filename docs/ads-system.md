## Слоты
- **Founder: жёсткий лимит 10.** Создание 11-го founder → отказ (waitlist / предложить standard). Счётчик «занято 7/10».
- **Standard/Premium: по сроку** (`ends_at`), авто-`expired` по дате.
- **Ротация:** если на одно место+город несколько активных — ротация по весу плана (premium чаще/выше). Не показывать все слоты только премиумом — оставлять место и другим.

## Жизненный цикл и ВСЕ сценарии
1. **Создание:** админ заводит draft → после подтверждения оплаты (СБП, honor-system, нет авто-биллинга) → publish (active).
2. **Founder-слот занят (10/10):** новый founder → отказ + waitlist, либо standard. UI показывает «места основателей закончились».
3. **Истечение срока:** `ends_at < now` → авто `expired`, перестаёт показываться. В кабинете — раздел «истекает скоро» (за 5 дней) + «истёкшие».
4. **Продление:** админ двигает `ends_at` → снова active.
5. **Пауза:** active→paused, не показывается. Опция: на паузе срок «замораживается» (сдвигать `ends_at` на длительность паузы) — честно к партнёру.
6. **Удаление:** soft-delete → `archived` (статистика сохраняется), убирается из ротации. Хард-делит — только админ.
7. **Нет реклам для места/города:** не показывать пустоту. Фолбэк — «домашний» баннер «Реклама в Юлдаше → стать партнёром» (ведёт на контакт).
8. **Таргет по городу:** реклама видна только в своих городах+местах. Поездка без города → общие (cities пусто).
9. **Овербукинг места:** ротация + приоритет премиума + лимит N на показ.
10. **Оплата (самозанятый, СБП):** админ вручную активирует после прихода денег. Без мерчанта авто-списаний нет.
11. **Напоминание об оплате/продлении:** дашборд «истекает через N дней».
12. **Статистика по рекламе:** `AdEvent` → показы/клики на объявление, видно админу и (позже) партнёру в его кабинете.
13. **Юр.маркировка (важно, РФ):** каждое объявление показывает **«Реклама · <рекламодатель>»** + хранит `erid`. Без этого — штраф по закону о рекламе. Уже есть поле `erid` — использовать обязательно.
14. **Founder «цена навсегда»:** место держится, пока партнёр платит/активен; перестал — админ паузит, слот можно освободить (решение админа, не авто).

- Список реклам: статус, план, срок, показы/клики, кнопки [пауза][продлить][удалить].
- Создание/редактирование: партнёр, контент, план, города, места, период, картинка, erid.
- Publish / pause / delete.
- Счётчик founder-слотов (7/10).
- Секции «истекает скоро» / «истёкшие».

## API (на рефакт-бэкенде, app/routers/ads.py)
- `GET /ads` — публично: только **active + в периоде**, отфильтровано по городу/месту, с ротацией. Маркировка в ответе.
- `POST /ads/{id}/event` — показ/клик (есть).
- `GET /ads/stats` — агрегат (есть).
- `GET /admin/ads` — все (admin).
- `POST /admin/ads` — создать (валидация founder-лимита 10).
- `POST /admin/ads/{id}` — обновить (контент/срок/статус).
- `POST /admin/ads/{id}/status` — publish/pause/archive.
- `DELETE /admin/ads/{id}` — архив.
- Все `/admin/*` — `role == admin`.
