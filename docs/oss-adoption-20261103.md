## План и границы

- [x] Добавить локальное формирование PDF в существующую квитанцию поездки через pdfme. Сохранить прежнее действие «Поделиться», текущую проверку владельца и существующее форматирование сумм.
- [x] Использовать только данные уже полученной квитанции: города, время, места, сумма, способ/статус оплаты. Не включать телефон, координаты, контакты, токены и другие поля ответа. PDF — информационная квитанция, без обещания фискального чека.
- [x] Проверять актуальность пользователя, поездки и экземпляра квитанции перед получением данных и перед фактическим скачиванием; закрытый экран/выход блокируют результат.
- [x] Подключать генератор лениво, шрифт хранить в проекте с лицензией. Не отправлять данные сторонним сервисам. Явно обработать загрузку, ошибку и повтор; все надписи RU/BA.
- [x] Проверить реальное содержимое PDF, башкирские символы, длинные строки, вредоносный текст как обычные данные, поздний результат после смены аккаунта и повторное нажатие.
- [x] Выполнить check/build, браузерную проверку на синтетических данных и независимую приёмку. Сохранить отдельный коммит, не выполнять push/merge/deploy.
