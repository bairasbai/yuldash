## Принципы

Эталон — дорого, плавно, лаконично. Ориентир: Яндекс Такси, inDrive, Uber, но **красивее**, а не копия.

1. **Собирай из готовых блоков**, а не из примитивов. Всё нужное — в `UiKit.kt`.
2. **Экран без состояний загрузки / пусто / ошибка — не готов.** Не только «успех».
3. **Цвет только из `Canon*`.** Хардкод `Color(0xFF…)` в экране запрещён (см. стоп-правила CLAUDE.md §11).
4. **Любая надпись — сразу RU + BA** через `appText()`.
5. **Тёмная тема бесплатно** — если взял цвет из `Canon*`, она уже работает.

## Типографика

Системный шрифт. Размеры **только в `sp`** — уважаем системный размер шрифта пользователя.

### Канон — эту шкалу используем

| Размер | Насыщенность | Что это |
|---|---|---|
| 28 sp | Black | Крупное число: сумма, цена, счётчик |
| 22 sp | Black | Заголовок экрана / шторки |
| 20 sp | Black | Заголовок секции (`SectionHeader`) |
| 18 sp | Black | Заголовок карточки |
| 16 sp | Black | Текст кнопки |
| 14 sp | Bold / обычный | Основной текст |
| 13 sp | обычный | Вторичный текст, подписи |
| 12 sp | обычный | Мелкое: метки, служебное |

Насыщенность: **Black** для заголовков и кнопок, **Bold** для выделения внутри текста, обычный — для тела. `Medium` почти не используется, новых не вводить.

### Как есть — разнобой, приводим постепенно

В коде живут ещё **10, 11, 15, 17, 24, 34 sp**. Самые массовые из них — 15 sp (~47 мест) и 17 sp (~19).
Разница между 15 и 14 глазом не видна. **Правило: трогаешь файл по задаче — заодно приведи размеры к канону.** Отдельную задачу «переписать все размеры» не заводим.

## Отступы

**Сетка 4 пункта.** Канон: `4 · 8 · 12 · 16 · 24`.

| Значение | Где |
|---|---|
| 4–8 dp | Между строками внутри одного блока |
| 12 dp | Между элементами списка |
| 16 dp | Внутренний отступ карточки — **основной** |
| 24 dp | Боковые поля экрана, крупные разделители |

Как есть: используются также `3, 6, 7, 9, 10, 11, 14, 18, 20, 22`. Самые массовые — 14 dp (внутри карточек) и 10 dp (между строками). Приводим постепенно тем же правилом.

## Формы и скругления

| Токен / значение | Для чего |
|---|---|
| `CanonCardShape` = 28 dp | Крупная карточка |
| `CanonItemShape` = 22 dp | Блок внутри карточки, элемент списка |
| 16 dp | Кнопка, поле ввода |
| 14 dp | Мелкий элемент, чип |
| 999 dp | Пилюля: фильтр-чип, бейдж |

Как есть: встречаются ещё `8, 12, 15, 18, 20, 24`. Считать дрейфом.

**Тень:** `elevation = 1.dp` у карточки. Больше не поднимать — тяжело выглядит.

## Компоненты

Всё в [`UiKit.kt`](../android/app/src/main/java/com/yuldash/app/UiKit.kt). Не изобретать заново.

### Кнопка — `AppButton`

Высота 54 dp (тач-цель с запасом), скругление 16 dp, текст 16 sp Black.

| Стиль | Заливка | Текст | Когда |
|---|---|---|---|
| `Primary` | `CanonGreen2` | белый | Основное действие экрана |
| `Accent` | `CanonGold` | `CanonGoldInk` | Брендовый акцент |
| `Secondary` | прозрачная, рамка 1.5 dp | `CanonGreen2` | Второстепенное действие |
| `Danger` | `CanonRed` | белый | Отмена, SOS |

Есть `loading` — показывает спиннер и блокирует нажатие. **Кнопку с сетевым запросом всегда делай через него**, не блокируй экран целиком.

### Карточка — `AppCard`

`CanonSurface` + рамка `CanonBorder` 1 dp + `CanonCardShape` + тень 1 dp. Передал `onClick` — получил лёгкое сжатие при нажатии.

### Заголовок секции — `SectionHeader`

Титул 20 sp Black + подпись 13 sp `CanonMuted`, зазор 2 dp.

### Состояния — `AppStateContainer`

Сам выбирает, что показать: грузим и пусто → скелетон; ошибка и пусто → `AppErrorState` с кнопкой «Повторить»; пусто → `AppEmptyState`; есть данные → контент.

⚠️ **Не показывать спиннер поверх уже загруженных данных.** Контейнер уходит в загрузку, только когда список пуст — иначе показывает старое и тихо обновляет. Не ломать это.

Для списков предпочитай `SkeletonCard` спиннеру — человек видит форму будущего контента.

## Анимации

Уровень iPhone: заметно, но не назойливо. Реальные значения из кода:

| Что | Как |
|---|---|
| Нажатие (`bounceClick`) | Сжатие до `0.97`, `tween(120)` |
| Появление карточки (`appearIn`) | Прозрачность 0→1 и сдвиг снизу 40→0, `tween(380)` |
| Каскад списка | Задержка `индекс × 55 мс` |
| Пульс скелетона | Прозрачность 0.45→1, `tween(820)`, туда-обратно |

Новые переходы держи в этом же диапазоне: **120 мс — отклик, 300–400 мс — появление.** Дольше 600 мс — воспринимается как тормоз.

⚠️ Тяжёлый `Canvas` с постоянной перерисовкой блокирует главный поток и **ломает саму анимацию** — уже ловили (см. `lessons.md`, 2026-06-29).

## Доступность

- Тач-цель **≥ 48 dp**, у кнопок фактически 54 dp.
- Контраст текста **≥ 4.5:1**, белого на цветной кнопке **≥ 3:1**. Три цвета под это уже подправлены — не откатывать.
- Текст **только в `sp`**.
- У иконки-кнопки — `contentDescription`, **на двух языках**.
- Списки — `LazyColumn`/`LazyRow` с `key`.
- Системные вырезы — через `WindowInsets` (`systemBarsPadding()` / `safeDrawing`).
- Башкирский текст обычно длиннее русского — вёрстка не должна ломаться.

## Так делай

- Бери готовое из `UiKit.kt`.
- Цвет — только `Canon*`.
- Все четыре состояния экрана.
- Каждая надпись через `appText(ru, ba)`.
- Новый экран → `enum Screen` + ветка в `when` внутри `YuldashApp()`.
- Ошибку показывай спокойно и с выходом: «Не получилось загрузить. Повторить?»

## Так нельзя

- ❌ `Color(0xFF…)` прямо в экране.
- ❌ Новый оттенок «почти как `CanonGreen`, но чуть светлее».
- ❌ Надпись на одном языке.
- ❌ Экран без состояний загрузки / пусто / ошибка.
- ❌ Спиннер поверх уже показанных данных.
- ❌ Своя кнопка вместо `AppButton`.
- ❌ Тень больше 1 dp.
- ❌ Обвинять пользователя в тексте ошибки.
- ❌ `appText()` и любой `@Composable` внутри тела `LazyColumn` — не соберётся.
