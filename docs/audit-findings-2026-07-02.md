## 🔒 В зоне параллельной сессии — НЕ трогал, передать ей / Александру

### [P1] respondToRequest — молчаливая потеря отклика водителя
[RidesRequestsChatScreens.kt:1354](RidesRequestsChatScreens.kt) — `ApiClient.respondToRequest(...).onSuccess { Toast; reload() }` **без `onFailure`**. При сбое сети водитель жмёт «Отправить», диалог закрывается ([:1355](RidesRequestsChatScreens.kt) `target = null` синхронно), **ничего не происходит** — ни ошибки, ни тоста. Водитель уверен, что откликнулся → потерянный заказ. Чинить: `.onFailure { Toast(двуязычно) }` + не гасить диалог до ответа.

### [P1/P2] respondToRequest — fire-and-forget диалог + нет валидации цены
[RidesRequestsChatScreens.kt:1352-1355](RidesRequestsChatScreens.kt) — `scope.launch{…}` запущен, но `target = null; price = ""; comment = ""` выполняются сразу (нельзя показать ошибку/спиннер; двойной тап → двойной отклик). Плюс цена `price.toIntOrNull() ?: 0` → можно отправить **0 ₽** как реальное предложение (кнопка всегда активна). Чинить: `var responding`, гасить в `onSuccess`/`onFailure`, `enabled = !responding`, отсекать пустую цену (или явно «договорная»).

### [P1] Время заявки выбрасывается (находка лида — data loss)
Форма «Создать заявку» ТРЕБУЕТ выбрать дату/время (кнопка disabled без него, `time.isNotBlank()`), но:
- `ApiClient.createRequest` ([ApiClient.kt:411-454](data/ApiClient.kt)) **не отправляет** `desired_at`/время — его нет среди `.put(...)`.
- Модель на сервере поле имеет: `RideRequest.desired_at` ([backend/app/models.py:177](../backend/app/models.py)) — но всегда NULL для заявок из приложения.
- При перезагрузке [YuldashApp.kt:438](YuldashApp.kt) ставит `time = «по договорённости»` (т.к. времени с сервера нет).
- **Итог:** пользователь выбрал конкретное время (обязательное поле), оно молча потеряно; водители не видят когда ехать. Обязательное поле бессмысленно.
- Чинить (3 файла): `createRequest` — принять+отправить `desired_at` (ISO); форма `CreatePassengerRequestScreen` ([AccessibilityScreens.kt](AccessibilityScreens.kt)) — распарсить выбранную строку в ISO и передать; `YuldashApp.kt:438` — `formatDepart(desired_at)` вместо «по договорённости», если есть. Бэкенд `requests.py` — сохранить (поле в модели уже есть).
> Примечание: мой фикс чеклиста «Проверка заявки» (сделал требование даты видимым) корректен, но обнажил, что само поле выбрасывается. После фикса отправки чеклист станет осмысленным полностью.
