## 1. Что это за работа и как её продолжать

### Метод одной волны — строго по шагам

Это не рекомендация, а протокол. Волна без любого из шагов не считается закрытой.

1. **Выбрать угол.** Не «посмотреть код», а вопрос про живого человека: «что будет, если
   женщина нажмёт SOS, когда сосед по сети выбрал лимит?»
2. **Доказать дыру пробой.** Временный файл `backend/tests/test_zz_probeNN.py`, который
   ЗАПУСКАЕТСЯ и печатает факты. Чтение кода доказательством не считается — я трижды
   «находил» дыру чтением, и трижды она оказывалась не дырой.
3. **Починить в одном шве.** Одно правило — одно место. Если правило проверяется в двух
   местах, они разъедутся; примеров в `lessons.md` десяток.
4. **Написать человеческий тест.** Имена функций по-русски, в тексте — бытовая ситуация,
   в сообщении `assert` — что именно теряет человек. Не «assert 403», а «женщина не сможет
   вызвать помощь».
5. **Мутации.** Сломать защиту → тест обязан покраснеть. **Обязательно и обратные мутации:**
   перестраховка не должна ломать нормальную работу (пример: «свежую заявку не дёргаем»).
6. **Полный прогон + линтер**, обновить документацию, коммит человеческим русским языком.

### Что считается хорошей находкой

Не «код некрасивый», а «человек теряет деньги, безопасность или доверие». Классы, которые
дали больше всего за 183 волны:

| Класс | Признак | Пример |
|---|---|---|
| **Две двери** | правило проверяется в одном месте, а входов два | бейдж «Проверен» снимался при смене машины через кабинет, но не через API |
| **Обещание vs код** | комментарий утверждает то, чего код не делает | «кнопка обязана сработать всегда» — а она делила лимит со всеми |
| **Ожидание без конца** | есть статус «ждём Х» и нет места, где он кончается сам | молчание обвинённого хоронило жалобу навсегда |
| **Защита бьёт по честному** | срок/лимит наказывает того, кто всё сделал правильно | водитель заплатил, админ не подтвердил — такси закрыли |
| **Право за чужой кнопкой** | чтобы воспользоваться своим правом, нужно чужое действие | нельзя удалить аккаунт, пока курьер не закроет посылку |
| **Тест ничего не проверяет** | сломай защиту — прогон зелёный | координаты текли до подтверждения брони |

## 4. Инструмент, который дал больше всего в конце: мутационный проход

Это главное, что стоит унаследовать.

**Идея.** Берём защиту, ломаем её в коде, прогоняем ВЕСЬ набор тестов. Если всё зелёное —
защиты фактически нет: она работает, пока её никто не трогает.

**Результат за волны 182–183.** Проверено 18 главных защит, 16 прикрыты, **две оказались
голыми**:

1. «Без подтверждённого номера в сервис нельзя» — убрал проверку, 3588 тестов зелёные.
   Причина: у тестовых людей номера вида `tg-test-7`, а заглушкой считается `tg` строго
   с цифрами. Тесты в это состояние просто не попадали.
2. Второй рубеж чистки координат из фото — страховка на случай, если первый не сработал.
   Пока первый работает, второй не выполняется ни в одном сценарии.

**Скелет скрипта** (клади во временную папку, не в репозиторий):

```python
import io, subprocess, sys
MUT = [("app/security.py", "<кусок кода как есть>", "<сломанная замена>", "имя мутации")]
for path, old, new, name in MUT:
    src = io.open(path, encoding="utf-8").read()
    if src.count(old) != 1:
        print(f"[SKIP] {name}: якорь встречается {src.count(old)} раз"); continue
    io.open(path, "w", encoding="utf-8", newline="\n").write(src.replace(old, new))
    r = subprocess.run([sys.executable, "-m", "pytest", "-q", "--no-header",
                        "-p", "no:randomly", "--timeout=300", "-x", "--tb=no"],
                       capture_output=True, text=True, encoding="utf-8", errors="replace")
    io.open(path, "w", encoding="utf-8", newline="\n").write(src)   # ВСЕГДА возвращаем
    print(name, "поймали" if r.returncode else "!!! НИКТО НЕ ЗАМЕТИЛ")
```

⚠️ **После каждого мутационного прогона — `git diff --numstat backend/app/`.** Если прогон
прервали (таймаут, перенос в фон), файл остаётся ИСПОРЧЕННЫМ, и следующая проба честно
покажет дыру, которой нет. Я на это попался в волне 183 и чуть не начал чинить собственную
поломку.

## 5. Ловушки среды (сэкономят тебе часы)

| Ловушка | Что делать |
|---|---|
| **Кириллица в heredoc** ломает bash («unexpected EOF») | скрипты-патчи пиши через Write в scratchpad и запускай `python файл.py` |
| **Вывод pytest в cp1251**, кириллица в консоли — каша | пиши вывод в файл, читай `io.open(..., encoding='utf-8', errors='replace')` |
| `PYTHONIOENCODING=utf-8 python ...` **перед** командой | в этом bash не работает как env-префикс; ставь внутри скрипта `sys.stdout.reconfigure` |
| **Окончания строк** — файл после записи с `\n` помечается изменённым | сверяй `git diff --numstat` (пусто = содержимое не менялось), потом `git checkout --` |
| **Общая база SQLite на сессию** | твои тесты не должны оставлять живых заказов/записей: уникальные имена, уборка за собой |
| **Скрипты документации не идемпотентны** | всегда проверяй `if метка in текст: выход` — иначе запись ляжет дважды (у меня легла пять раз) |
| **Тестовые пользователи** `user_factory` | телефон `tg-test-N`, роль водителя авто-одобряется; для проверки «нового» водителя нужен `taxi_approved=False` |

**Команды:**

```bash
# полный прогон бэкенда (~6 минут)
cd backend && python -m pytest -q --no-header -p no:randomly --timeout=300

# линтер ровно как в CI
cd backend && python -m ruff check app/ --select F

# покрытие
cd backend && python -m pytest tests/ -q --cov=app --cov-report=term-missing

# сборка Android (~10 минут)
cd android && JAVA_HOME='C:\Program Files\Android\Android Studio\jbr' ./gradlew.bat :app:assembleDebug :app:testDebugUnitTest --no-daemon
```
