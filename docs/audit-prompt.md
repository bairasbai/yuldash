## ⛔ Пять правил, нарушение которых портит прод

Прочитай это до всего остального. Это не стиль, это ущерб.

### 1. Проверь, КУДА смотрит сборка, прежде чем что-либо создавать

Отладочная сборка берёт адрес сервера из `YULDASH_DEBUG_API_BASE_URL` в `local.properties`
(если строки нет — из значения по умолчанию в `app/build.gradle.kts`). **Проверено
2026-08-04: и там, и там сейчас `http://10.0.2.2:8000`, то есть локальный сервер.**

Но полагаться на это нельзя: значение правится одной строкой, и если в нём окажется
`https://yulbash.ru`, то любой демо-пользователь, тестовая поездка или посылка,
созданные «для проверки», лягут в НАСТОЯЩУЮ базу рядом с реальными людьми.

**Перед первым созданием чего бы то ни было — посмотри строку своими глазами:**

```bash
grep YULDASH_DEBUG_API_BASE_URL android/local.properties
```

Меняешь её — верни как было сразу после. Файл с локальными настройками **в git
не коммитить**: проверь `git check-ignore -v <файл>` прежде чем поверить, что он
игнорируется.

**Как поднять локальный сервер** (порт 8000, отдельная sqlite-база, прод не трогается):

```bash
cd backend && DATABASE_URL="sqlite:///./demo_local.db" ENV=dev   JWT_SECRET="dev-secret-change-me-please-1234"   .venv/Scripts/python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
```

Если эмулятор до `10.0.2.2:8000` не достучался (частая причина — брандмауэр Windows
режет входящие к python.exe), **не лезь в настройки брандмауэра**. Обходится без прав
администратора: `adb reverse tcp:8000 tcp:8000` плюс временно
`YULDASH_DEBUG_API_BASE_URL=http://localhost:8000` (этот хост уже разрешён в
`network_security_config.xml`). После работы верни строку обратно.

### 2. Не трогать `mobile/`

Старый Flutter, заброшен. Работа идёт только в `android/`.

### 3. Ни ключей, ни секретов в git

Включая `docs/`, комментарии и примеры в отчётах. Ключ MapKit живёт в `local.properties`.

### 4. ЮKassa и юридическое лицо — НЕ ТРОГАТЬ

Прямое указание владельца. Денежные флаги (`parcel_fee_enabled`, `payouts_enabled`,
`tips_money_enabled`) выключены сознательно: публичная оферта на `yulbash.ru/terms`
обещает «комиссия не берётся», и пока флаги выключены — это правда. Включишь флаг —
сделаешь оферту ложной. Не включай.

### 5. Сборка и эмулятор — один агент за раз

Вторая параллельная сборка ломает первую. `MainActivity.kt` правит **один** агент
в один момент — последняя запись затирает чужую. Подробности — скилл `orchestration`.

## 📋 План: 20 итераций

Порядок не по алфавиту, а по риску: сперва то, что решает «можно ли запускаться»,
потом то, что упирается в чужие действия.

Каждая итерация заканчивается: **зелёная сборка → зелёные тесты → скриншот
эмулятора → обновлён `docs/` → короткий отчёт**.

### Блок A · Что решает запуск (итерации 1–6)

| # | Этап | Что делаем |
|---|---|---|
| 1 | **Инвентаризация** | Прочитать `docs/`, свести реальный список фич/ролей/эндпоинтов. **Найти мёртвый код**: эндпоинты, которые никто не зовёт, и вызовы к тому, чего на сервере нет |
| 2 | **Плохие сценарии — сеть** | Выключить сеть на эмуляторе (`adb shell svc data disable`) и пройти **каждый** экран. Что показывает? Есть ли «Повторить»? Не падает ли? Не крутится ли спиннер вечно? |
| 3 | **Плохие сценарии — сервер** | Подменить ответы на 401/403/404/409/500/таймаут. 401 (не вошёл) **не должен** говорить «проверь интернет». Локальный бэкенд + правка ответов, не прод |
| 4 | **Плохие сценарии — пользователь** | Отказ в правах на гео и уведомления · отмена на каждом шаге заказа · двойной и тройной тап по кнопке · поворот экрана посреди формы · сворачивание на активной поездке |
| 5 | **Безопасность: доступ к чужому** | Попробовать открыть чужую бронь, чужой заказ, чужой чат, чужую посылку **по номеру**. Проверить, что админ-эндпоинты закрыты для обычного пользователя. Это IDOR, самая частая дыра |
| 6 | **Безопасность: данные и секреты** | Телефоны и точные координаты **не должны** попадать в логи и в Sentry (скрубберы уже есть — проверить, что работают). Лимиты запросов на вход и SOS. Секретов в git нет |

## ✅ Критерии готовности

- [ ] Ни один экран не падает при выключенной сети, на 500 и при отказе в правах
