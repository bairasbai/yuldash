# 💰 План монетизации Юлдаша (перед реализацией) — 2026-07

> Документ для согласования ДО кода. Как сделать приложение прибыльным, **не нарушая философию**:
> сперва польза людям → заработок идёт на развитие → честный бонус автору. Всё честно, прозрачно, с умом.
> Рынок — Республика Башкортостан + соседние районы (анализ — `docs/` + ресёрч 2026-07).

---

## 0. 🕊 Красные линии (правила, которым подчиняется КАЖДЫЙ вариант)

Это не «пожелания», а жёсткие рамки. Любая фича монетизации проходит проверку по ним:

1. **Зарабатываем на созданной ценности, не на чужой беде.** Взяли деньги → реально помогли (довезли дешевле, нашли пассажиров, привели клиента бизнесу).
2. **Честно и прозрачно.** Никакого мелкого шрифта, скрытых наценок, «тёмных паттернов». Пользователь всегда видит, за что и кому платит.
3. **Доверие не продаём.** Бейджи «проверен», рейтинг, «кто пригласил», безопасность (SOS) — всегда бесплатны. Это продукт, а не товар.
4. **Личные данные не продаём и не сливаем.** Никогда. Только обезличенная агрегированная аналитика (и то — осознанно).
5. **Не грабим час-пик.** Сурж уже с честным потолком ×1.5 — не поднимать.
6. **Реклама — полезная, ненавязчивая.** Местный бизнес, релевантный поездке. Не на весь экран, не всплывающая поверх SOS/заказа.
7. **Добровольность.** Донаты, подписки, купоны — всё по желанию. Отказ ничего не ломает и не наказывается.
8. **Попутка (Путь А) остаётся бесплатной для людей.** Деньги — с бизнеса и такси, не с попутчиков между своими.

## 1. 🗺 Рынок в двух словах (почему модель именно такая)

- **37% населения — село** (одна из самых сельских республик РФ). Постоянный поток «райцентр ↔ город».
- **Медианный доход ~61 тыс ₽** → люди считают деньги, скидки и купоны бьют точно.
- **Трёхъязычие** (русские 36% / башкиры 29,5% / татары 25,4%), мусульманские праздники, Сабантуй, крепкие общинные связи → «между своими» тут не маркетинг, а образ жизни.
- **Дыра в рынке:** Яндекс — Уфа + премиум-межгород; местные конторы — межгород по звонку; BlaBlaCar — длинный межгород. А **райцентр↔село и дешёвый доверенный межгород «между своими»** — ничей. Это наша зона.
- **Вывод:** главный денежный движок — НЕ комиссия с бедных пассажиров, а **местный бизнес, который платит нам за доступ к потоку едущих людей** (купоны, реклама, партнёрство).

## 3. 🔍 Детально по каждому варианту

### A. Комиссия такси 3 → 5 → 8% *(готово)*
- **Как:** с завершённого такси-заказа лесенкой по стажу таксиста (готово в `config`, `debt`). Модель А «на доверии» — водитель платит долг раз в неделю.
- **Ты зарабатываешь:** основной доход, когда включишь такси (`TAXI_ENABLED`).
- **Честность:** втрое ниже Яндекса, промо 0% первым; всё видно водителю.
- **Строить:** ничего, только активировать. Позже — Модель Б (выплаты через платформу) для авто-списания.

### B. Boost поездок *(готово)*
- **Как:** водитель платит за подъём своей поездки в выдаче (ЮKassa/СБП). Цены — с бэкенда.
- **Ты зарабатываешь:** сразу, даже до полноценного такси.
- **Честность:** не заплатил — просто в общей очереди по времени. Никого не задвигаем «в минус».
- **Строить:** ничего. Опц.: тарифы Boost вынести в конфиг/админку.

### C. ⭐ Купонный маркетплейс *(главный новый — строить)*
- **Идея:** местный бизнес (кафе/АЗС/шиномонтаж/СТО/магазин/аптека) размещает купоны для едущих людей. Пользователь получает **реальную скидку**, бизнес — клиента, ты — деньги за то, что свёл их.
- **Ты зарабатываешь (3 способа, комбинируются):**
  1. **Подписка партнёра** ~990–2990 ₽/мес за место в «Скидки по пути».
  2. **Оплата за результат** — X ₽ за каждый **активированный/погашенный** купон (бизнес платит только за клиента).
  3. **Выделенная метка на карте маршрута** — премиум-место, дороже.
- **Что строить (бэк):** модель `Partner` (бизнес), `Coupon` (заголовок, скидка, город/маршрут, срок, лимит), `CouponRedemption` (кто, когда, погашено). Эндпоинты: партнёр CRUD купонов, пользователь — список по маршруту/городу + активация (код/QR), бизнес — подтверждение погашения, счёт/статистика. Биллинг партнёра (подписка/за погашение) — сначала «на доверии» по СБП (как всё), потом ЮKassa.
- **Что строить (UI):** пользователю — раздел «Скидки по пути» (лента купонов по городу/маршруту, экран купона с кодом/QR); партнёру — кабинет (создать купон, статистика, счёт); экран погашения (бизнес вводит/сканирует код).
- **Честность:** метка «Партнёр Юлдаша»; пользователю никакой скрытой наценки — только выигрыш; купон честный (реальная скидка, срок, лимит видны).
- **Философия:** это и есть «зарабатываем, помогая» — все трое в плюсе.

### D. Кабинет партнёра + локальная реклама *(частично готово — F20)*
- **Как:** `Ad` + `is_advertiser` + кабинет рекламодателя уже в коде. Бизнес размещает карточку/баннер (кафе, СТО), нативно в ленте/на карте.
- **Ты зарабатываешь:** плата за размещение (подписка/за показы).
- **Строить:** довести кабинет до купонов (см. C) — это одна связка «Партнёр». Реклама и купоны живут в одном кабинете партнёра.
- **Честность:** реклама местная, релевантная, помечена, не навязчивая.

### E. ⭐ Промокоды и кампании *(строить — рычаг роста)*
- **Как:** на базе реферала — именные промокоды («код BAIMAK» → скидка/бонус пользователю, трек тебе). Для блогеров, партнёров, акций.
- **Ты зарабатываешь:** не напрямую — это **инструмент привлечения** (блогеры, вирусность), который кормит A–D. Блогерам платим **на результат** (за активных приведённых), а не за просмотры.
- **Что строить (бэк):** модель `PromoCode` (код, тип бонуса, лимит, срок, владелец-кампания), `PromoRedemption`; эндпоинты создать/активировать/статистика; связь с реферал-бонусами.
- **Что строить (UI):** поле «ввести промокод» при регистрации/в профиле; админ/партнёр — создание кампании + статистика (сколько привёл, сколько активных).
- **Честность:** измеримо (реальные активные, а не накрутка — B8-анти-фрод переиспользуем); блогер получает по факту.

### F. B2B-партнёрства *(частично — F22 клиники)*
- **Как:** страховая (ОСАГО таксистам), банк (карты под СБП/выплаты), автосервисы/АЗС-сети, автошколы, клиники/аптеки (расширить F22).
- **Ты зарабатываешь:** % с приведённых клиентов / фикс за интеграцию / реклама.
- **Строить:** точечно под конкретного партнёра (реф-ссылки, спец-предложения). Базы — реферал + кабинет партнёра (C/D/E) уже дают инструменты.
- **Честность:** предлагаем то, что реально нужно (ОСАГО таксисту всё равно оформлять — почему не у нашего партнёра со скидкой).

### G. Доставка посылок между сёлами *(категория есть — монетизировать)*
- **Как:** категории `parcel`/`cargo` уже в коде. Реальная боль села — передать лекарство/документы/вещи в райцентр с попутным водителем.
- **Ты зарабатываешь:** небольшой сервисный сбор за посылку (или комиссия, как с такси).
- **Строить:** тариф/сбор за посылку, подтверждение получения, простая «эстафета» (кто везёт, кто получил). Безопасность: не возим запрещённое (дисклеймер + правила).
- **Честность:** сбор маленький, видимый; попутка людей остаётся бесплатной — платится только за вещь-доставку.

### H. Корпоративные аккаунты *(строить — позже)*
- **Как:** предприятие/вахта возит сотрудников, платит с баланса компании.
- **Ты зарабатываешь:** B2B-доход (предоплата/счёт).
- **Строить (позже):** модель `Company` + баланс + сотрудники + отчёты. Отдельная фаза, когда пойдёт объём.

### I. Донаты «Поддержать Юлдаш» *(готово)*
- **Как:** добровольный перевод на платформу (готово, `/support/donate`).
- **Ты зарабатываешь:** фоновый доход + вовлечённость («мы делаем вместе»).
- **Честность:** только добровольно, без давления, прозрачно («на серверы, карты, SMS»).

### J. Подписка «Юлдаш+» *(осторожно / позже)*
- **Как:** для частых пассажиров — приоритет, без наценки в час-пик, доп-удобства.
- **Риск (⚠️):** легко скатиться в «плати или страдай» — против философии. Делать ТОЛЬКО если базовый сервис остаётся полноценным без подписки (плюсы — приятные, не «выкуп страдания»).
- **Строить:** позже, аккуратно, после купонов/рекламы. Не приоритет.

### K. Праздничные кампании (Сабантуй и др.) *(сезонные события есть — F15)*
- **Как:** к Сабантую/праздникам — промо-пакеты бизнесу, «доехать на Сабантуй вместе», спец-купоны. Сезонные события уже в коде.
- **Ты зарабатываешь:** пиковые продажи рекламы/купонов вокруг событий.
- **Честность:** культурно, к месту, полезно.

## 4. 🛠 Что строить технически (по фазам)

Общая база для C, D, E, F — **единый «Партнёрский слой»**. Строим его один раз, дальше все денежные фичи растут из него.

### Фаза M1 — Партнёрский слой + Купоны (ядро дохода) ⭐
- **Бэк:** модели `Partner`, `Coupon`, `CouponRedemption`; эндпоинты (партнёр CRUD, пользователь список+активация, погашение, статистика); биллинг «на доверии» по СБП + счёт партнёру; миграция.
- **UI:** «Скидки по пути» (пользователь) + кабинет партнёра (создать купон, статистика) + экран погашения. Всё двуязычно.
- **Активация:** ты подключаешь первых бизнесов вручную (пилотный город + 1 маршрут).

### Фаза M2 — Промокоды и кампании (блогеры/рост)
- **Бэк:** `PromoCode`, `PromoRedemption`, связь с рефералом; эндпоинты создать/активировать/статистика.
- **UI:** ввод промокода; кабинет кампании со статистикой активных.

### Фаза M3 — Доставка посылок (монетизация категории)
- **Бэк:** сбор за посылку, подтверждение получения, правила.
- **UI:** оформление посылки + статус.

### Фаза M4 — B2B и корпораты (по мере роста)
- Точечные партнёрские интеграции (F) + корпоративные аккаунты (H).

### Готово/активировать без стройки
- A (комиссия), B (Boost), D-реклама (F20), I (донаты), K (события F15) — включаются флагами/админкой.

## 5. 📊 Что мерить (метрики честной монетизации)
- Доход по источникам (комиссия / купоны / реклама / Boost / посылки).
- Купоны: показы → активации → погашения (воронка), доход на партнёра.
- Партнёры: сколько активных, удержание (продлевают ли подписку).
- Влияние на пользователей: не растёт ли отток из-за рекламы (следим — если растёт, режем нагрузку).

## 6. 💵 Порядок дохода (грубо, честно)
- **Пилот (1 город + 1 маршрут):** 20–40 партнёров × ~1500 ₽/мес ≈ **30–60 тыс ₽/мес** (купоны+реклама), + Boost.
- **Раскатка на районы:** 54 района × ~10 партнёров × 1500 ₽ ≈ **сотни тысяч ₽/мес** + комиссия такси сверху.
- Цель — устойчивый доход на развитие + честный бонус автору, а не «нажиться».

## 7. 🧑‍💼 Что остаётся Александру (вне кода)
- Подключать первых бизнесов-партнёров (продажи), финальные цены подписки/за-погашение.
- Юр.часть: договоры с партнёрами, оферта для рекламодателей, налоги.
- Активация флагов (`TAXI_ENABLED`, ключи ЮKassa для авто-биллинга позже).
- Финальный башкирский (черновики → `docs/tasks.md`).

## 8. ✅ Проверка каждой фазы (стандарт Юлдаша)
- Все состояния UI (загрузка/пусто/ошибка), двуязычно, тёмная тема, `Canon*`.
- Деньги — int-копейки; телефоны/координаты не логируем; секреты в env.
- pytest зелёный + миграции идемпотентны + сборка Kotlin (CI `android-build`).
- Прогон по красным линиям (§0) — каждая фича проходит проверку на честность.
