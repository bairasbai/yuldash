## ✅ Что в релизе сделано ХОРОШО (не ломать)
- **Auth/приватность — уровень Signal:** refresh one-time + `with_for_update` (TOCTOU), OTP `compare_digest`+5 попыток, вебхук под секретом, `authenticate_ws` чтит ревокацию, телефоны/координаты/токены не логируются.
- **Share-ссылки** — 128-бит токен, `unique`, TTL 24ч, гео только пока поездка живая, `no-store/noindex`, отзыв «сжигает» токен. Грамотный capability-URL.
- **IDOR закрыт** во всех новых потоках (инстант/курьер/посылки/family/route-watch/trust/медданные) — проверка владельца/участника везде.
- **Деньги не доверяют клиенту:** цену считает сервер, самокредит невозможен, купон гейтится владельцем бизнеса, вебхук ЮKassa перепроверяет статус.
- **Миграции:** одна голова `merge_20260720`, DAG цел, NOT NULL всегда с `server_default`, downgrade у всех, чистый прогон на SQLite. **Уже свели `migrate_*.sql`→`archive/` + Alembic** (моя рекомендация B3 из архитектурного ревью — сделана).
- **Реалтайм на 5 воркерах** через Redis pub/sub, WS-хендлеры под guard, пере-auth раз в 15 кадров, XSS закрыт.
