- 2026-06-23 — `UserLocationLayer.arrow.setIcon(...)` в MapKit lite по факту НЕ применяется: при движении (а эмулятор всегда даёт курс) рисуется дефолтная тёмная стрелка-треугольник; `arrow.setVisible(false)` → метки нет вовсе (pin в режиме движения тоже скрыт). Кастомный pin работает, но его почти не видно (эмулятор постоянно в arrow-режиме). Правило: нужен ТОЧНЫЙ вид метки «я тут» → не воевать с `UserLocationLayer`, а рисовать СВОЙ `PlacemarkMapObject` через android `LocationManager` (GPS+NETWORK), обновлять `geometry` по фиксам. Полный контроль, никакого треугольника. Камера: цель чуть южнее точки (~-0.0022° на zoom 15), иначе точка уходит под нижнюю плашку (центр MapView под картой).
- 2026-06-23 — Android `View.OnTouchListener`: если `onTouch` вернул `false` на `ACTION_DOWN`, listener НЕ получает последующие `MOVE`/`UP` этого жеста. → нельзя детектить пан/щипок там, возвращая false (логика мёртвая). Для реакции на жесты карты (держать точку при зуме) — использовать Yandex `CameraListener` (`reason == CameraUpdateReason.GESTURES`, флаг `finished`): щипок ловим по изменению `pos.zoom` (>0.05) и возвращаем камеру на точку. Пан-детект по «zoom не менялся» ненадёжен — лучше пан оставить свободным.
- 2026-06-24 — Интерактивная карта (`MapView`/`AndroidView`) ВНУТРИ `LazyColumn` = конфликт жестов: вертикальный пан карты борется со скроллом страницы (`requestDisallowInterceptTouchEvent` помогает, но Compose-скролл не всегда уважает legacy-intercept; на эмуляторе синтетика вообще не двигала карту). Правило: карту держать ВНЕ прокрутки — `Column { шапка+карта (фикс) ; LazyColumn(weight 1f){ остальное } }`. Тогда пан/зум карты без конфликта. Паттерн всех карт-приложений (карта фикс, контент-лист скроллится поверх/ниже).
- 2026-06-23 — Тест жестов карты через adb НЕнадёжен: `input swipe` и вертикальный `input motionevent` НЕ панорамируют Yandex MapView (вертикаль скроллит родительский `LazyColumn`); горизонтальный `input motionevent DOWN/MOVE/UP` иногда панорамирует. Щипок (2 пальца) adb практически не воспроизводит. Вывод: жесты карты (пан/зум/щипок) проверять на реальном устройстве/мышью в окне эмулятора, а не adb-синтетикой. Кнопки/FAB проверяются тапами норм.
