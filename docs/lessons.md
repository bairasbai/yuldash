- 2026-06-23 — Android `View.OnTouchListener`: если `onTouch` вернул `false` на `ACTION_DOWN`, listener НЕ получает последующие `MOVE`/`UP` этого жеста. → нельзя детектить пан/щипок там, возвращая false (логика мёртвая). Для реакции на жесты карты (держать точку при зуме) — использовать Yandex `CameraListener` (`reason == CameraUpdateReason.GESTURES`, флаг `finished`): щипок ловим по изменению `pos.zoom` (>0.05) и возвращаем камеру на точку. Пан-детект по «zoom не менялся» ненадёжен — лучше пан оставить свободным.
- 2026-06-24 — Интерактивная карта (`MapView`/`AndroidView`) ВНУТРИ `LazyColumn` = конфликт жестов: вертикальный пан карты борется со скроллом страницы (`requestDisallowInterceptTouchEvent` помогает, но Compose-скролл не всегда уважает legacy-intercept; на эмуляторе синтетика вообще не двигала карту). Правило: карту держать ВНЕ прокрутки — `Column { шапка+карта (фикс) ; LazyColumn(weight 1f){ остальное } }`. Тогда пан/зум карты без конфликта. Паттерн всех карт-приложений (карта фикс, контент-лист скроллится поверх/ниже).
