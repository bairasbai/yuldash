## Отдельные серверные инварианты

- **YGO-I01 Идемпотентность намерения (P0):** Actor + command + operation ID + payload hash и receipt; replay сохраняет исходный результат, другой payload конфликтует. Критерий: Потерянный ответ/повтор не создаёт второй ресурс; ключ не переносит права аккаунта. Полная гарантия main не установлена. Основание: проект shared-backend, C01-r1, C18-r1, C31-r1.

- **YGO-I02 Версия и outcome изменения (P0):** Pending operation, authoritative result и observation cursor раздельны; expected revision проверяется транзакционно. Критерий: Истечение polling/удаление local marker не считается rollback; после reconnect читается исходный outcome. Полная гарантия main не установлена. Основание: проект shared-backend, C15-r1, C09-r1.
