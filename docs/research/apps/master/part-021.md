# Pro Удаление null order и Go C61 Локальные поля сериализации

## Pro Null order до первого удаления из памяти

В выбранной null-ветви manager сначала ожидает DAO удаления cache по ID, затем заново читает текущий order из своей map, создаёт terminated record и ожидает repository operation. Отсутствие записи в map, non-terminated step или null reason вызывают guard-исключение после предшествующего normal DAO-result, но до первого map.remove этой invocation. Это не означает, что map вообще не могла меняться другими вызовами.

# Pro Условная привязка executor к LazyDatabase
