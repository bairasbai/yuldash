# Export content review

Scope: only the requested ordinary research Page contents. No redactions were made.

Automated pattern checks found no private-key headers, GitHub-style tokens, OpenAI-style API keys, AWS access-key IDs, JWT-shaped credentials, credential-value assignments, email addresses, phone-number candidates, private assistant memory paths, or localhost/private-IPv4 URLs. Security terms such as password/token/authorization occur in technical research descriptions, not detected credential values. Hashes and source-code identifiers remain as evidence.

This is a heuristic screen, not a guarantee that every sensitive value can be detected. Local audit evidence paths and source file identifiers may appear in original research prose; these are references only, not exported filesystem contents. All limitations and unexecuted-test caveats remain unchanged.

The source Pages are personal and access-controlled. Publishing these exported documents to a public repository is a separate action requiring the owner’s public-publication approval. Public publication of this evidence-only snapshot was explicitly authorized by the owner. Only the approved research contents are included; source access metadata, account identifiers and internal work files are excluded. The manifest records only logical document names, titles, sequence numbers, block counts, chunk layout and content hashes; it omits extracted Page IDs, parent IDs, source URLs and timestamps.
