Что реализовано (код + тесты, pytest зелёный):

- ✅ **Тесты** `backend/tests/test_observability.py` (7): статусы компонентов,

### 🔧 Что осталось активировать Александру (без кода, только конфиг):

1. **Создать проект Sentry** (sentry.io) — отдельно для бэка (Python/FastAPI) и Android.
2. **Положить DSN в секреты** (НЕ в git):
   - прод-сервер: в `.env` → `SENTRY_DSN=https://...`;
   - Android: в `local.properties` → `YULDASH_SENTRY_DSN=https://...`.
3. **(Опц.) Задать порог алертов** в прод-`.env`: `ERROR_ALERT_THRESHOLD=10`,
   `ERROR_ALERT_WINDOW_SEC=300`, `ERROR_ALERT_COOLDOWN_SEC=900` (значения по умолчанию
   уже разумны — трогать только если нужно чувствительнее/тише).
4. **Задеплоить бэк** (`pip install -r requirements.txt` подтянет `sentry-sdk`) и
   пересобрать Android-релиз, чтобы DSN попал в сборку.

Без шагов 1–4 всё уже работает как раньше — Sentry и алерты просто спят (no-op).
