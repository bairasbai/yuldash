## Исправления и подтверждение

Денежная блокировка исправлена в двух helper (`app/debt.py`, `app/routers/courier.py`): `FOR NO KEY UPDATE` по-прежнему исключает конкурирующие денежные записи, но позволяет проверку внешнего ключа уведомления. Четыре новых проверки сначала падали, после исправления проходят, включая сохранность незавершённых изменений вызывающей стороны. Тест: `backend/tests/test_postgres_courier_notification.py`.

В миграциях воспроизведено **семь сбоев**: пять PostgreSQL и два SQLite. Это enum→text в частичном индексе; повторное создание индексов в трёх миграциях; ревизия длиной 33 символа при колонке VARCHAR(32); удаление столбца SQLite до внешнего ключа; удаление столбца до его индекса. Исправлены шесть файлов миграционной инфраструктуры. Условие индекса сравнивает enum напрямую; наличие индексов проверяется до DDL; колонка версии расширяется до VARCHAR(128); откат удаляет зависимости до столбцов.

Итоговый цикл `upgrade head → downgrade base → upgrade head` прошёл на изолированных PostgreSQL и SQLite. Отдельно проверено расширение существующей PostgreSQL-колонки VARCHAR(32). Логи в `test-results/`: `pg-migration-review-final-down.log`, `pg-migration-review-final-up.log`, `sqlite-migration-review-up.log`, `sqlite-migration-review-down3.log`, `sqlite-migration-review-reup.log`.

## Как повторить проверку

Все команды — из backend/, через Python проекта. Для каждого нового PostgreSQL-прогона создавать отдельную пустую базу: тестовые идентификаторы повторяются между процессами. DATABASE_URL должен указывать только на эту тестовую базу. Сначала `python -m alembic upgrade head`, затем `python -m pytest -q --junitxml=<отдельный XML>`. PostgreSQL-профиль использует локальные ограничения ожидания блокировок; никакие запросы не отменять вручную ради зелёного результата.

Адресный профиль: test_postgres_courier_notification.py, test_payment_postgres_concurrency.py, test_audit_fix_be35.py, test_wallet_is_not_charged_twice.py, test_the_wallet_works_one_way_for_couriers.py, test_the_wallet_pays_for_what_is_already_paid.py, test_last_seat_race.py, test_audit_fix_be06.py, test_audit_fix_be06_retries.py, test_audit_fix_be23.py. Полный набор запускается без фильтра и без исключения падавших тестов.
