## Назначение

Купонный маркетплейс «Скидки по пути» — витрина скидок от местных заведений-партнёров для
пассажира. Две вкладки: «Скидки рядом» (публичный список `getCoupons`, фильтр-чипы по городу,
по умолчанию — родной город из профиля) и «Мои купоны» (активированные, `getMyCoupons`). Тап по
купону → детальная карточка → «Активировать скидку» (`activateCoupon`) → крупный одноразовый КОД
для показа в заведении. Скидку физически даёт заведение, не Юлдаш (честный дисклеймер на экране).
Жалоба «тут что-то не так» (`reportCoupon`) ставит купон перед глазами админа, но не снимает его.

Файл также хранит переиспользуемые по всему приложению хелперы: `couponCategoryIcon`,
`couponCategoryLabel`, `kopToRub`, `shortDate`, `ufaIsoDate` — их вызывают/будут вызывать
`PartnerCabinetScreen`, `AdminPromoScreen`, `AdminParcelsScreen`, `CarPhotoScreen`,
`DriverProfileScreen`, `TaxiDocsScreens` (вне зоны этого листа).

## Связи

  `activateCoupon`, `reportCoupon`, `ApiClient.me()` (кешируется, для дефолтного города).

  `backend/app/timeutil.py::client_dt_to_utc` (форма шлёт голую дату → сервер кладёт как начало дня
  по Уфе). Серверная логика проверена листом 1.3 — здесь проверялось только то, как Android читает
  и показывает её ответы.
- `shortDate`/`couponLastAcceptedDay`/`ufaIsoDate`/`kopToRub`/`couponCategoryIcon`/`couponCategoryLabel`
  переиспользуются в `PartnerCabinetScreen.kt`, `AdminPromoScreen.kt`, `AdminParcelsScreen.kt`,
  `CarPhotoScreen.kt`, `DriverProfileScreen.kt`, `TaxiDocsScreens.kt` (все вне зоны).
- `ApiException`/`genericByStatus` (`ApiClient.kt`) — общий перевод HTTP-кодов в двуязычный текст;
  экран использует как fallback, если сервер не прислал свой `detail.ru/ba`.

## Остаток и ограничения

- Независимое ревью (Opus) вернуло лист на первом проходе: главный блокер (R2) и 7 более мелких
  пунктов разобраны выше и исправлены; этот проход — вторая версия карточки.
- `CouponFilterChip` (строка 394) не трогал, хотя использует тот же `height(48.dp)`, что и
  `CouponTab` до фикса R6: города обычно короче «Яҡындағы ташламалар» и не на половине экрана,
  риск обрезки ниже, но не нулевой (например «Иглино» на башкирском может быть длиннее). Не
  зафиксировано отдельным тестом — сознательный приоритет в пользу явно указанных ревью пунктов.
- `PremiumBadge` (строка 456): иконка и текст оба подписаны «Премиум» — TalkBack читает слово
  дважды подряд. Мелочь из ревью, не чинил (не влияет на деньги/доступность по существу, только
  на благозвучие озвучки) — оставляю как есть, не стал множить несущественные правки.
- Башкирский черновик, требует проверки Александром как носителем (см. отчёт, раздел «Башкирские
  черновики»): `"Ебәреп булманы. Ҡабатла."` (reportErrDefault).
- `reportErrDefault` (строка про «Не получилось отправить») реально используется только при
  обрыве сети (не-`ApiException`) — для любого HTTP-ответа с кодом ошибки `ApiException.message`
  уже заполнен `genericByStatus`/`detail`, и до `reportErrDefault` дело не доходит. Проверить ИМЕННО
  эту строку тестом не удалось: `MockResponse().setSocketPolicy(NO_RESPONSE)` внутри открытого
  `AlertDialog` с полем, в которое только что вписан текст (фокус + мигающий курсор), не даёт
  Robolectric дождаться «Compose idle» — тест падает по таймауту ожидания раньше, чем успевает
