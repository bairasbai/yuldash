## Назначение

Калькулятор дохода АВТОРА (админ-инструмент для Александра) — чистый расчёт на клиенте, без
сервера. Показывает оценку месячной выручки/чистыми с бизнеса (купоны, Boost, опционально
комиссия такси) и честную экономику водителя (валовый − бензин − комиссия). Не пользовательский
экран — Александр показывает его партнёрам и сам крутит ползунки.

## Остаток и ограничения

Экран не пользовательский (админ-инструмент), поэтому стандартные состояния
загрузка/пусто/ошибка к нему неприменимы — расчёт мгновенный и локальный. Визуальная проверка
на эмуляторе (как ползунки выглядят и реагируют на палец) не делалась — только Robolectric
через точный `SemanticsActions.SetProgress`, не настоящий жест пальцем.

**P3, не блокирует (из отчёта ведущему):**
- Строки ~103–109 используют `Color.White` вместо `CanonOnAccent` (тот же белый цвет, но
  хардкод вместо токена) — `CanonSourceGuardTest` цвета не проверяет, правило держится на
  ревью. Решение за Александром.
- При жадных настройках бензина «чистыми водителю» показывает «0 ₽» (`coerceAtLeast(0.0)`),
  но строка расшифровки ниже вычитает полную отрицательную сумму («−10 800 000 ₽ бензин») из
  валовых 600 000 ₽ — числа визуально не сходятся. Для «честной экономики» было бы честнее
  показать сам убыток. Решение за Александром.
- У ползунков и тумблера «Включить такси» нет текстовой подписи для TalkBack (слышны только
  проценты/число, не «Поездок в день: 80») — админ-экран, не блокирует.
