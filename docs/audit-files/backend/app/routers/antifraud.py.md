## Назначение
Админ-поверхность анти-фрода: баны устройств (банит/снимает/смотрит список ТОЛЬКО человек) и
журнал помеченных текстов (кто/что/где помечено — без самого текста). Вся логика — в `antifraud.py`
(наш же лист), здесь — HTTP-обвязка и admin-only гейт.

## Найденные ошибки
Ошибок не найдено. Приватность проверена: `device_id` не попадает ни в `admin_action` (журнал
действий), ни в ответ бана по `user_id` в виде текста лога — только в теле HTTP-ответа админу,
который и так видит это устройство как админ. `admin_text_flags` отдаёт `user_phone` — это
СОЗНАТЕЛЬНОЕ решение (докстринг: «админу нужен контакт, чтобы связаться»), ручка admin-only,
чужой пользователь её не видит (`_require_admin`).

## Остаток и ограничения
`_require_admin` использует однозыковый `HTTPException(403, "Только для админа")`, а не `herr(ru,ba)`.
Это НЕ моя находка и не ошибка — та же конвенция повторяется в `ads.py`, `coupons.py`, `drivers.py`
и других чужих роутерах; собственный сторож проекта (`test_every_refusal_speaks_both_languages.py`,
см. `docs/architecture.md`) ЯВНО исключает `/admin/…`-ручки из требования двуязычия (админ — один
человек, Александр). Менять существующую повсеместную конвенцию в рамках одного файла листа не стал.
