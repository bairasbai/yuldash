# Карточка: `backend/app/routers/reviews.py`

- Статус: verified
- Лист: leaf-3.2
- Проверял: Sonnet 5 (leaf-3.2); принимал: Opus 5.5

## Назначение
Два независимых потока модерации под одной крышей: (1) отзывы о ПРИЛОЖЕНИИ для лендинга
(`AppReview`: создать/мои/публичные/админ-очередь/публикация) и (2) текстовые отзывы о ПОЕЗДКЕ
(`Rating.text`: админ-очередь/публикация/«щит рейтинга» — снять спорную оценку из среднего).
