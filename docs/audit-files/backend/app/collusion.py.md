- Статус: verified
- Лист: leaf-3.2
- Проверял: Sonnet 5 (leaf-3.2); принимал: Opus 5.5

## Назначение
Детект накрутки доверия сговором (Sybil) — только СИГНАЛ админу (`routers/sybil.py`) на ручной
разбор, авто-наказаний нет. Три признака: взаимный реферал, взаимные 5★ (по всем трём сервисам —
попутка/такси/доставка), много завершённых поездок ровно между одной парой.

## Функции и разбор
| Функция / участок | Строки | Что делает | Условия, входы, ошибки | Вердикт |
|---|---|---|---|---|
| `_pair` | 28–30 | Неориентированный ключ пары (меньший id первым) | A/B и B/A дают один ключ | ок |
| `reciprocal_invites` | 33–42 | Пары со взаимным рефералом (A→код B И B→код A) | У честных так не бывает — код вводят один раз | ок |
| `mutual_high_ratings` | 45–76 | Пары со взаимными 5★ (≥`min_each`=2 с каждой стороны), по DISTINCT поездкам всех трёх сервисов | Оценка без привязки к поездке (все `None`) пропускается — не к чему привязать | ок |
| `pair_trip_counts` | 79–110 | Много завершённых поездок РОВНО между той же парой (≥4 за все три сервиса) | Поездка с самим собой (`one==two`) не считается | ок |
| `find_suspects` | 113–142 | Сводит три сигнала, сортирует по числу сигналов (счёт = убедительность) | `SCAN_CAP`=100000 строк на запрос — ограничение памяти, отдаётся в ответе | ок |
