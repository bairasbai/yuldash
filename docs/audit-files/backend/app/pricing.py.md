## Назначение

Внешние и локальные сигналы для цены такси: реальное расстояние/время в пути с учётом пробок
(Яндекс.Маршруты), текущая непогода (Яндекс.Погода), сложность подачи (по живому водителю
рядом). Деньги в копейках тут НЕ считаются — это модуль множителей/метрик, которые потом
использует ценовой движок (`instant_service.py`, вне зоны). Главный принцип: любой внешний
источник fail-safe — нет ключа, таймаут, 429 или мусор в ответе возвращает детерминированный
локальный расчёт (хаверсин × коэффициент дорог) и нейтральный множитель погоды. Короткий
in-process кэш (не Redis) округляет координаты, чтобы не хранить точные адреса и не долбить
внешний API на каждый чих.

## Связи

- Используется ценовым движком такси (`instant_service.py`, вне зоны листа) для построения
  итоговой цены — множители объединяются через `combine_market_factors`.
- Настройки: `taxi_external_pricing_enabled`, `yandex_router_key`/`yandex_weather_key`,
  `taxi_avoid_tolls`, `taxi_external_timeout_sec`, `taxi_route_cache_sec`/`taxi_weather_cache_sec`,
  `taxi_weather_max_k`, `taxi_pickup_free_min`/`full_min`/`max_k`, `surge_max_k`,
  `instant_road_k`, `instant_avg_speed_kmh`.
- `services.haversine_km` — локальная формула расстояния для фолбэка.
