# Карточка: `backend/app/antifraud.py`

- Статус: verified
- Лист: leaf-3.2
- Проверял: Sonnet 5 (leaf-3.2); принимал: Opus 5.5

## Назначение
Ядро анти-фрода (батч B8, прагматичный v1 без ML): бан устройства, отвязка «перепроданного»
номера, сигнал о новом устройстве, анти-телепорт GPS, анти-фишинг и модерация открытых текстов
(телефон/увод в мессенджер/мат). Принцип файла: автоматика только ПОМЕЧАЕТ, банит человек.

## Найденные ошибки
Ошибок не найдено. Отдельно проверено правило приватности (§8 CLAUDE.md, «личные данные не в
логах»): во всём файле ровно 3 вызова `log.*` — `notify_phone_release` (только `user_id` +
константа дней), `_count_teleport`/`count_text_flag` (только `user_id` и вид метки). Ни один
не получает на вход телефон, координаты или сырой текст сообщения — структурно нечего "забыть
заскрабить" (в отличие от `safety.py`/`sos_escalate.py`, где есть `scrub_exc(e)` для чужих
исключений, в этом файле `except Exception:` везде либо молчит полностью, либо логирует без
содержимого исключения — `str(e)`/`{e}` в файле НЕТ вовсе, грепом подтверждено).
