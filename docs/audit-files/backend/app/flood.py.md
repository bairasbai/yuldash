# Карточка: `backend/app/flood.py`

- Статус: verified
- Лист: leaf-3.2
- Проверял: Sonnet 5 (leaf-3.2); принимал: Opus 5.5

## Назначение
Два переиспользуемых потолка на поток действий ОДНОГО человека (анти-флуд, защищаем людей,
не сервер): «сколько висит одновременно» (`guard_open_items`) и «сколько раз за минуту»
(`guard_burst`). Плюс готовые двуязычные тексты отказов.

## Функции и разбор
| Функция / участок | Строки | Что делает | Условия, входы, ошибки | Вердикт |
|---|---|---|---|---|
| `guard_open_items` | 32–40 | Потолок ОТКРЫТЫХ объектов (активные поездки/заявки/посылки) | Читает не больше `limit+1` строк (дёшево); `n>=limit` → 429 | ок |
| `guard_burst` | 43–54 | Потолок ТЕМПА (создано за последнюю минуту) | `n>=per_minute` → 429; используется заявками/посылками/бронями/откликами/отзывами о приложении | ок |

## Связи
`routers/bookings.py`, `routers/parcels.py`, `routers/requests.py`, `routers/reviews.py` (наш
лист) — все чужие вызывающие файлы (кроме reviews.py), сами guard-функции не трогал за пределами
файла. Чат (`routers/chat.py`) использует СВОЙ ОТДЕЛЬНЫЙ `_guard_chat_burst`, НЕ эти функции
(важно для карточки — не перепутать при выборе теста на поломку, см. «Остаток»).
