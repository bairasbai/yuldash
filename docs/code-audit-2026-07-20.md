2. **CI:** добавить джоб `postgres:16+postgis` (разблокирует тест гонки брони `test_overbooking_concurrent` и PostGIS-гео — сейчас скипаются/не исполняются) + `ruff`/`gitleaks`/`pip-audit` + ночной `assembleDebug`.
3. **Тесты reject-путей:** вебхук платежа при `status!=succeeded` (сейчас mock всегда `succeeded` → защита от реплея не покрыта); двойная активация платежа под гонкой.
4. **Вебхук:** дедуп `update_id` (replay-защита).
