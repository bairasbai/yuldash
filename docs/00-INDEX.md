## 🎯 СТАТУС РЕАЛИЗАЦИИ (2026-06-30) — АКТУАЛЬНОЕ (от кода, не от старых доков)

> Свежий снимок: что РЕАЛЬНО реализовано на сейчас. Блоки ниже (2026-06-28 и старше) — история. Этот — главный.

**Приложение:** Kotlin/Compose, ~45 экранов в ~16 файлах (UI давно разрезан из `MainActivity.kt` — он теперь тонкое ядро ~664 строки: `enum Screen/HomeTab`, демо-данные; экраны в своих файлах). 5 вкладок: Карта / Поездки / Заявка / Чат / Профиль. Двуязычие RU/BA (`appText`). Цвета `Canon*` (свет/тьма). **Стартовый экран — всегда КАРТА** (Home); первый запуск — Intro; не вошёл — Login.

**Бэкенд:** FastAPI + PostgreSQL(PostGIS) + Redis (5 воркеров gunicorn) на `yulbash.ru` (HTTPS). Фабрика `main.py:create_app()` + роутеры `app/routers/*` (health/auth/rides/requests/bookings/drivers/chat/discovery/family/safety/location/payments/ads/reviews). Все правки этой сессии **задеплоены и проверены** (pytest 73 passed, server-side health/journal чисты).

### Карта и поездки (production-ready ядро):
- **Маршрут** — Яндекс DrivingRouter по дорогам, основной зелёный + до 2 объездных серым (`routesCount=3`); фоллбэк прямая при квоте/ошибке; камера фитит весь путь; ключ MapKit в `local.properties` (НЕ в git).
- **Live-стрелка попутчика** — нав-стрелка, едет по дороге, **плавно** (chaser 60fps, сглаживание адаптивно по плотности подачи + зуму), нос по `bearing`. WS `/ws/trip/{booking_id}/location` (реле; направленные ключи `-bid*2`/`-bid*2-1` → без self-эхо; перепроверка токена/статуса раз в 15 сообщений). Foreground `TripLocationService` шлёт GPS ~раз в 7с. **Приватность:** точное гео только в активной поездке. **Проверено код-тестом 2 WS-клиентов** (без 2 телефонов) — нашёл+починил баг self-эхо.
- **ETA** — общее «≈ … в пути» + **живой остаток** «≈ … осталось» (от позиции по маршруту, уменьшается).
- **Демо-симуляция** — кнопка «▶ Симуляция» (ТОЛЬКО `BuildConfig.DEBUG`): фейк-попутчик едет по дорожному маршруту, постоянная скорость по длине; посмотреть live-стрелку без 2 телефонов. В релизе кнопки нет.
- **Статус-вотчер активной поездки** — поллинг `/bookings/{id}/role` раз в **~12с** (на паузе в фоне, `repeatOnLifecycle`) → пассажир видит **live-баннер** «Водитель выехал / подъезжает» (бэк хранит `Booking.driver_phase`).
- **Авто-обновление пинов** — раз в **~25с** (пауза в фоне) **+ WS-пуш** `/ws/map`: при новой поездке/заявке/брони/отмене сервер шлёт «refresh» → клиент мгновенно перетягивает `/rides/near`+`/requests/near` (дебаунс 1.5с). Новые появляются сами, исполненные/уехавшие исчезают.
- **Фильтры «Ближайшие»** (чипы) — 6: Только женщины / Детское кресло / С животным / Багаж / Кондиционер / **Некурящий**. Те же в «Фильтры по умолчанию».
- **Заявки на карте** — оранжевые маркеры «ищет попутку»; тап → карточка (имя, маршрут, места, ≈км, коммент) + «Откликнуться» (цена/коммент → `respondToRequest`). Телефон не показываем.

### Заявки пассажира (end-to-end):
- **Форма «Создать заявку»** — город/время/места/цена/категория + **карточка «Условия поездки» (7 переключателей):** Только женщины, Детское кресло, С животным, Инвалидная коляска, Багаж, Некурящий салон, Кондиционер. Поля `RideRequest`/`RequestIn` (миграция `migrate_request_prefs.sql`).
- **Лента заявок водителю** (`RequestsFeedScreen`) — карточки с **чипами условий** (видит, подходит ли), дистанция, «Откликнуться».
- **Поток** заявка → отклик → `accept` → создаётся Ride+Booking (поездка с чатом + кодом посадки). E2E на проде.

### Лента карты (`/feed`): счётчики поездок (день/неделя/месяц/год) + топ-маршрут + **счётчик донатов за всё время** (`donations_total` = сумма подтверждённых `purpose=donate`). Карусель `QuickSearchCard`, карточка «💚 Поддержка · X ₽ собрано».

### Жизненный цикл: бронь `pending→confirmed→done/cancelled` (FOR UPDATE, идемпотентна, clamp мест); водитель `departed/arriving/done` (push + `driver_phase`); завершение чистит live-позицию (приватность) + снимает маршрут.

### Что ФЕЙК/ручное (честно):
- 💸 **Платежи** (Boost/донат) — СБП «на доверии» (счётчик + реквизиты, без эквайринга; ждёт юр.лицо/54-ФЗ).
- 🛂 **Модерация водителей** — авто-OCR прав (Яндекс Vision) + **ручное** одобрение админом.
- 📲 **Push (FCM)** — настроен end-to-end, на реальном устройстве не подтверждён.
- 🗂 **`Mocks.kt`** — демо-данные ТОЛЬКО как фолбэк при оффлайне.

### Бэклог (реальные фичи, не баги): пересчёт маршрута при отклонении (попутки ≠ навигатор — низкий приоритет), условия заявки в карточке на КАРТЕ, `onboard`-подстатус (live и так на `confirmed`), e2e live-трекинг на 2 реальных телефонах (логика доказана код-тестом), цвет маршрута в тёмной теме.

### Сессия 2026-06-30 (что добавлено/починено): live-трекинг WS-реле + плавная нав-стрелка (chaser, зум-адаптив, по дороге) + ETA-остаток + демо-симуляция; объездные маршруты; статус-вотчер; авто-refresh карты + WS-пуш пинов; условия в заявке (7) + показ водителю; счётчик донатов; фильтр «Некурящий» (6 фильтров); аудит карты/поездок (5 агентов, реальные дыры закрыты: приватность координат заявок, WS-перепроверка, само-стоп сервиса); фиксы: маршрут не исчезает при зуме, старт всегда Карта, тогл «Я на линии» (честное «войдите» вместо «проверь сеть»), висячая «·» в «Проверка заявки»; убрана кнопка «Поездки в больницу». **Финальный APK собран (clean, BUILD SUCCESSFUL).**
