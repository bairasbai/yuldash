# 🔎 Чего не хватает в Такси и Курьере — разбор полноты продукта (2026-07-26)

> **Вопрос Александра:** «Чего ещё не хватает в такси, в курьере? Всё ли реализовано? Все ли ситуации учтены?»
> **Метод:** 6 параллельных проверок ПО КОДУ (не по докам): сценарии заказа, деньги/водитель,
> курьер+посылки, экраны Android, сравнение с Яндекс/inDrive/Максим, аварийные ситуации.
> Каждая находка ниже перепроверена лидом грепом по коду. Доки обещают больше, чем сделано, — верим коду.
> **Это оценка, не работа.** Ничего не менял; список — вход для планирования.

---

## Вывод одной фразой

**«Всё хорошо» сделано отлично. «Что-то пошло не так» — почти не сделано.**
Счастливый путь такси и курьера закрыт плотно (85 тестов, все основные эндпоинты подключены к
экранам). Но как только сценарий отклоняется — заказ завис, курьер заболел, груз разбили, человек
не пришёл — система молчит, а у Александра нет ни одной кнопки, чтобы вмешаться.

**Главный факт:** система «Справедливость» (861 строка: двусторонний разбор, фото, апелляция,
лестница) написана на сервере и **полностью отсутствует в приложении** — слов `incidents`,
`standing`, `evidence` в `android/` нет ни разу. Конфликт сегодня нести некуда.

## 🟠 ВАЖНО — не убьёт запуск, но будет больно каждый день

**Такси:**
- **Нельзя написать комментарий водителю и указать подъезд** (`instant.py:61-74`). «Ленина 12» в селе — пять домов без табличек. Ориентир сказать негде: чат открывается только после принятия.
- **Нельзя заказать такси для другого человека.** В заявках-попутках поле есть (`for_relative_name`, `models.py:306`), в такси-заказе нет ничего. Для села это основной сценарий: сын из Уфы вызывает такси маме.
- **«Я на месте» жмётся откуда угодно** — координаты не проверяются (`instant.py:434`), а с этого идёт платное ожидание и штраф пассажиру.
- **Время подачи показывается неверное** — это длительность самой поездки А→Б (`instant_service.py:311`), а не «водитель через 3 минуты».
- **Нет чека за такси** (квитанция только для попуток, `bookings.py:222`) и **нет кнопки «оплатил наличными»** — заказы за нал навсегда «не оплачены».
- **Забытые вещи** — процесса нет; чат после поездки только на чтение.
- **Зимний протокол и «застрял на трассе» работают только для попуток**, для такси-заказов нет — хотя именно там 4 часа трассы зимой.
- **Чаевых в такси нет** (только для попуток, `family.py:446`).

**Курьер:**
- **Телефон отправителя курьеру не выдаётся** — только получателя (`parcels.py:179`). Курьер приехал забирать, никого нет, позвонить нечем. **Работа: 1 час.**
- **Курьерам не приходят уведомления о новых заказах** — пуши есть только отправителю. Заявка висит в пустоте, три курьера едут мимо.
- **Объявленная ценность всегда 0** — поля в форме нет, спор всегда падает в ветку «ценность не объявлена».
- **Фото нет ни в одной точке** — ни при заборе, ни при вручении, ни повреждения. Хранилище `/upload/evidence` готово, его просто не зовут.
- **Курьер не видит свой заработок** — только «должен Юлдашу столько-то». У таксистов заработок по дням сделан полностью.
- **Комиссию курьера можно не платить** — блокировки как у такси нет (`courier.py:115`).
- **Отмена посылки бесплатна на любой стадии** — курьер проехал 40 км, отправитель отменил, компенсации нет.
- **У доставки «по пути» нет цены вообще**, а сбор 30/60/120 ₽ попадает в отчёт «собрано», хотя платёжного пути для него в коде нет — цифра в админке показывает деньги, которых нет.
- **Стать курьером = селфи + «легковой/грузовой».** Ни ФИО, ни номера машины, ни галочки согласия с правилами.
- **Приостановленный за нарушения спокойно берёт посылки** — `ensure_active` в доставке не стоит (в попутках/такси я его поставил в этом же аудите).

**Общее:**
- **Текстовые отзывы никогда не публикуются** — бэкенд-очередь модерации есть (`reviews.py:131`), экрана нет. В профилях вечно только звёздочки.
- **Категория SOS всегда `other`** — приложение не шлёт реальную (`SosVerifyScreens.kt:373`). Админ не отличит «сердце» от «пробил колесо». Правка на одну строку.
- **Сроки ОСАГО и разрешения не проверяются** — это просто картинки без дат. Одобрили в июле — возит с просроченным ОСАГО в декабре.
- **Кошелёк таксиста всегда пустой по устройству** (в Модели А деньги мимо нас), но показывает «Доступно к выводу» — выглядит как потеря денег.

## 🟢 ПОТОМ — рост, а не запуск

Из сравнения с Яндекс/inDrive/Максим — реальных белых пятен всего пять, и все они про рост:

1. **Торг о цене** (механика inDrive) — половина уже есть: водитель предлагает цену в откликах, пассажир ставит потолок. Нет второго круга и торга в такси-режиме. Для села торговаться — привычка, а не неудобство.
2. **Абонемент на регулярные поездки для пассажира** — «каждый будний день 7:20 Темясово→Баймак». Сторона водителя готова (`Ride.recurrence`), пассажирской подписки нет. Главный сценарий республики.
3. **Корпоративные клиенты** (больница, школа, вахта — счёт раз в месяц). Ноль в коде. Единственный источник предсказуемой выручки в райцентре. Осторожно: ломает модель «платформа не касается денег».
4. **Телефонная диспетчерская** — готова на ~80% (админ заводит заявку, автоподбор лучшего отклика работает), не хватает номера и экрана диспетчера. Самый дешёвый способ получить аудиторию без смартфонов.
5. **Ночной/утренний тариф** — в модели `Tariff` измерения времени суток нет вообще. В −30 в 5 утра по дневной цене никто не поедет. **Работа: маленькая.**

Почти бесплатные хвосты (бэкенд готов, Android не зовёт): достижения `/me/achievements`,
трекинг-ссылка посылки получателю, подсказки водителю «почему мало откликов», подписка на заявки
по направлению.

**Сознательно НЕ делать:** свой эквайринг для поездок (разрушит юр-модель «на доверии» —
главное преимущество), подписку типа Плюс, кэшбэк деньгами, оплату частями, аукцион в реальном
времени (в селе онлайн 2-3 водителя), счётчик по GPS, премиум-класс, веб-админку.

## 📋 Если делать по порядку (моя рекомендация)

**Неделя 1 — «чтобы не сломалось» (≈5 дней):**
1. Фоновый воркер (одна работа — закрывает три блокера): активация предзаказов, закрытие
   зависших заказов, повтор поиска + очередь «рядом никого».
2. Кнопки админа: закрыть заказ такси, отменить/переназначить посылку, снять курьера.
3. Дыра «Я оплатил» (лимит нажатий) + списание долга при подтверждённом «не заплатил».
4. Связать спор с посылкой (1 день — механика компенсации уже написана).
5. Отказ курьера от заказа + статус возврата.

**Неделя 2 — «чтобы доверяли» (≈5 дней):**
6. Госномер + комментарий водителю + подъезд + заказ для другого человека.
7. Телефон отправителя курьеру (1 час), пуши курьерам о заказах, `ensure_active` в доставке.
8. SOS: список у админа + статус «принял» + SMS админу вместо только Telegram + уведомление о
   тикетах поддержки (15 минут).
9. Не удалять жалобы/SOS, где человек — фигурант (обезличивать), + выгрузка по запросу.

**Неделя 3+ — Android:** «Центр справедливости» (бэкенд полностью готов), экран модерации
отзывов, история заказов такси, заработок курьера, чек за такси, забытые вещи.

**Потом — рост:** ночной тариф (дёшево) → торг о цене → абонемент → диспетчерская → корпоративные.
