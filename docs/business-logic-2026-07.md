> Собрано из решений Александра + проработки. Это **что и почему**, до кода. Меняется только по согласованию.
> Статус решений: ✅ решено · 🔧 дефолт (можно менять цифрой) · ⚖️ финал за юристом · 🧭 маркетинг/решение Александра.

## 1. Суть продукта
**Юлдаш = гибрид «BlaBlaCar + Яндекс Такси» для своих, по Башкортостану.** Два режима в одном приложении:
- 🚗 **Попутка** — «еду по своим делам, подвезу» (разделение расходов). Ядро и душа.
- 🚕 **Такси** — «работаю, зарабатываю сейчас» (коммерческая перевозка).
Отличие от конкурентов: **«между своими»** — доверие, башкирский, земляки, забота, комиссия втрое ниже, работает там, где Яндекса нет.

---

## 2. Два режима — как работают

### 🚗 Попутка (BlaBlaCar) ✅
- Пассажир оставляет заявку (Сибай→Уфа) → водитель откликается → бронь → чат → согласовали.
- Или водитель публикует поездку → пассажир сам бронирует.
- Цену ставит **водитель** (подсказка-ориентир есть). Комиссия **0%**.
- Доступна **всем** с машиной, **без лимита часов** (человек и так едет).
- Пассажир, выбравший «Попутку», не смешивается с такси-потоком.

### 🚕 Такси (Яндекс-стиль) ✅
- Водитель выходит «на линию», выбирает зону работы (город/район · межгород · соседний регион).
- Пассажир выбирает «Такси» → точка А–Б → сервер считает цену → подбор ближайшего → оффер с таймером → поездка → оплата.
- Пассажир-«такси» попадает **только** к таксистам на линии (попутка не касается).
- Комиссия по лесенке (см. §5). Лимит **8 часов** (см. §8).

**Переключение режимов** — ясным сегмент-переключателем у пассажира (🚗 Попутка / 🚕 Такси, разные цвета, подсказка «Два способа доехать»). У водителя — две зоны в кабинете (Попутка / Такси). *(Уже реализовано, PR #45.)*

## 3. ⚖️ Юридическая модель (Путь А + Путь Б, такси за admin-переключателем)
- **Путь А — Попутка = разделение расходов, НЕ такси.** Лицензия/разрешение/самозанятость не нужны, **если это честное разделение** (по пути, цена ≈ доля бензина, не поток заказов ради заработка). Запускается свободно. ✅
- **Путь Б — Такси = коммерческая перевозка (580-ФЗ).** Легально при условиях:
  - водитель: **самозанятый (НПД)** + **разрешение на такси** (реестр перевозчиков) + **ОСАГО** + машина в реестре;
  - Юлдаш зарегистрирован как **«служба заказа такси»** (реестр служб заказа);
  - приложение **проверяет** документы на входе в такси; нет — только попутка.
- **Реализуем ОБА пути в коде.** Такси-режим — за флагом `taxi_enabled` (по умолчанию **false**, показывает «Скоро»). Александр оформляет документы → ставит **true** → такси включается мгновенно. ✅
- ⚖️ **Финал — с живым юристом по перевозкам** (ответственность агрегатора при аварии, ОСГОП, договоры с водителями, чек 54-ФЗ при безнале). Попутку можно запускать раньше.

## 5. 💸 Деньги

### Комиссия (доход платформы) ✅
- **Такси: 3% (1-й месяц) → 5% (2-й) → 8% (навсегда).** Ниже всех: Яндекс 22–30%, Drivee ~12,8%, Максим/inDrive — от низкой до ~15%, Uber в РФ отдельно не работает.
- **Попутка: 0%.**
- Первым водителям при старте — **0% на 3 месяца + бесплатный Boost** 🧭.

### Оплата ✅
- **Старт (Модель А, «на доверии»):** наличные + СБП **напрямую водителю**. Комиссия — долг водителя платформе (см. ниже).
- **Модель Б (готово, ВЫКЛ):** деньги через платформу → комиссия автоматом → выплата водителю на карту. Включается с ИП + бизнес-ЮKassa (флаг `payouts_enabled=false`). *(Реализовано, PR #36/#44.)*

### Долг по комиссии (Модель А) ✅ *(реализовано, PR #43)*
- За завершённый такси-заказ копится долг 8% (или 3/5% в льготный период).
- Раз в неделю водитель переводит долг Александру по СБП → «Я оплатил» → **Александр подтверждает** в админке.
- Просрочка / долг > порога → **режим такси блокируется** («оплати долг»). **Попутка работает.**

### Тарифы такси (сервер считает сам, клиенту не верит) 🔧
Модель как у Яндекса по структуре (база + ₽/км + ₽/мин + минимум), цены — свои, ниже:
| Зона | База | ₽/км | ₽/мин | Минимум |
|---|---|---|---|---|
| Город | 70 ₽ | 11 ₽ | 3 ₽ | 100 ₽ |
| Межгород | 80 ₽ | 9 ₽ | 2 ₽ | 150 ₽ |
*(Реализовано, PR #42. Цифры в конфиге — правятся без пересборки.)*

### Сурж (наценка в час пик) ✅ 🔧
- Только при **реальном спросе** (много заказов, мало машин рядом).
- **Потолок ×1,5.** Ступени ×1,1 / ×1,2 / ×1,3 / ×1,5.
- **Прозрачно ДО заказа:** «Сейчас много заказов, цена выше на 20%. Вызвать или подождать?».
- **На попутке суржа НЕТ.**

### Отмены и ожидание (как Яндекс, 1 в 1 по структуре) ✅ 🔧
| Ситуация | Юлдаш |
|---|---|
| Отмена в первые 3 мин / до выезда водителя | бесплатно |
| Отмена, когда водитель едет/приехал | штраф = подача (~70 ₽) |
| Бесплатное ожидание после подачи | 5 мин |
| Платное ожидание | +5 ₽/мин (Яндекс +9) |
| Пассажир не вышел | 5 мин ожидания + 3 мин → водитель отменяет, пассажир платит подачу |
Всё показываем заранее и прозрачно.

### Другие доходы (чтобы комиссию держать низкой)
- 📢 Реклама местного бизнеса (кабинет рекламодателя) — потенциально главный доход.
- 🚀 Boost (водитель платит за поднятие поездки).
- 🌱 «Поддержать Юлдаш» — добровольно (20/50/100 ₽). *(Реализовано, PR #42.)*
- 🏥 B2B медцентр-партнёр — позже.

## 7. 🧾 Требования к водителю такси (Путь Б) ✅ 🔧
- Самозанятость (ИНН/статус НПД), разрешение на такси, ОСАГО, водительские права, фото авто + госномер.
- Возраст **20+**, стаж **от 3 лет** (580-ФЗ). ⚠️ В коде было 2 года — исправлено 2026-07-26,
  правило применяется к НОВЫМ заявкам; уже одобренных задним числом не пере-проверяем.
- **Сроки документов живут:** ОСАГО, разрешение и диагностическая карта хранятся с датами,
  фоновая задача напоминает за 14 и за 3 дня и снимает допуск к такси после истечения
  (попутка при этом работает). Продление — без пере-подачи заявки.
- **Предрейсовое подтверждение** (честный минимум по 580-ФЗ): раз в день перед выходом на линию
  водитель подтверждает самочувствие, исправность машины и отсутствие алкоголя. Это
  САМОДЕКЛАРАЦИЯ, не медосмотр — так и написано в интерфейсе. Остаётся записью для разбора.
- Класс «Эконом» на старте.
- Проверка — **вручную Александром/модератором** на старте; авто-проверка статуса самозанятого — позже.
- Попутка требований такси НЕ требует (обычная проверка водителя).

## 7.5 📦 Доставка и курьер — правила ✅ 🆕 (2026-07-26)
Раздела не существовало вовсе: слов «курьер / посылка / доставка» в этом документе было **0**,
хотя режим работает в коде. Кто за что отвечает — решалось в переписке, а не на бумаге.

**Кто может возить.** «По пути» (poputka) — любой попутчик, без отдельной проверки. Режим
**курьера** (courier / «купи и привези») — только одобренная заявка: селфи с документом, ФИО,
госномер машины, согласие с правилами. Приостановленный за нарушения новые посылки не берёт.

**Что нельзя возить.** Запрещённое к перевозке (оружие, наркотики, скоропорт без упаковки,
живые животные без согласования), а также вскрывать посылку. Согласие с этим — галочка при
регистрации курьера и при создании посылки.

**Границы ответственности — по фото.** Курьер фотографирует посылку при получении («взял целой»)
и при вручении («отдал целой»). Фото приватные: видят только стороны спора и разбирающий.
Без фото спор решается по объявленной ценности и здравому смыслу.

**Объявленная ценность.** Указывает отправитель, ≤ 1 млн ₽. Это НЕ страховка — ориентир при
разборе. Не указана → в споре опираемся на чек/фото/договорённость сторон.

**Вручение.** Только по коду от получателя. «Купи и привези» — сначала фактическая стоимость
покупки, потом вручение (потолок выкупа защищает курьера от больших авансов).

**Если что-то пошло не так:**
- курьер **не может везти** → снимает себя с заказа, посылка возвращается в общий список;
- получателя нет / отказался → **возврат отправителю**; комиссию платформы за возврат НЕ берём
  (услуга не оказана);
- отправитель отменил, когда курьер уже выехал → фиксируем компенсацию курьеру (Модель А:
  сумма фиксируется, деньги идут мимо платформы);
- спор о повреждении/пропаже → «Центр справедливости»: обе стороны объясняются, решает человек.

**Деньги.** Оплата доставки — напрямую курьеру. Комиссия платформы (лесенка 0/5/8%) копится
долгом и платится в кабинете; при неоплаченной комиссии от 1000 ₽ новые заказы недоступны.

**Сколько стоит «по пути».** Цену называет **отправитель** при создании заявки — сколько он
заплатит попутчику. Попутчик видит эту сумму **до того, как возьмёт посылку** (раньше цены не
было вообще: он соглашался вслепую). Пусто = «по-соседски, бесплатно» — это нормальный ответ
для села, и он так и подписан обеим сторонам. Деньги идут из рук в руки, платформа их не касается.

**Сбор платформы за «по пути» сейчас не берём — и это решение, а не забывчивость.** Тариф
(30/60/120 ₽ по размеру) в коде остался, но выключен флагом `PARCEL_FEE_ENABLED`. Причина:
платить его физически некому. Попутчик — не курьер: кабинета, долга и способа перевести деньги
у него нет; выставлять счёт бабушке-отправительнице мы тоже не будем. Пока сбор начислялся
«в воздух», а в отчёте админа он показывался строкой «собрано» — то есть в отчёте были деньги,
которых не существует. Включим в тот день, когда появится реальный путь оплаты.

**Что видит админ в отчёте по доставкам** — три разных числа, а не одно:
- **Курьеры оплатили** — комиссия, которая реально дошла;
- **Ждём от курьеров** — начислено и ещё не оплачено (долг, путь оплаты есть);
- **Сбор «по пути»** — начислен тарифом, но никому не выставлен. Это **не выручка**.

**Трекинг.** Отправитель может выдать получателю ссылку — тот следит за доставкой в браузере,
без приложения и без телефонов в ссылке. Ссылку можно отозвать (ошиблись номером).

## 8. 🌙 Отдых водителя (8-часовой лимит) ✅
- Отработал **8 часов на линии в такси** (попутку не считаем) → **такси блокируется.**
- Разблокировка — **утром следующего дня** (с ~6:00) и не раньше **8 часов отдыха.**
- Не рубим посреди заказа — даём завершить.
- **Один попутчик на обратную дорогу:** если смена кончилась в другом городе — можно взять **ОДНОГО** попутчика домой (машина и так едет назад). Второй заказ/публикация — нельзя до отдыха.
- В отдых — **вежливые, нечастые** сообщения: «хорошо поработал, отдохни 🌙», сезонные советы, «кто-то ищет попутку в твою сторону», местное полезное (позже — ненавязчивая реклама).

## 9. 🛡 Качество, рейтинги, наказания ✅
- **Взаимная оценка:** пассажир↔водитель.
- **Анонимно:** водитель видит «рейтинг снизился / пришла жалоба на грубость», но **НЕ видит, кто** пожаловался/поставил звезду. И наоборот. Мести неоткуда.
- **Перечень жалоб** — на водителя (нахамил / высадил / опасное вождение / обман с ценой / грязная машина / опоздал / угроза безопасности / другое) и на пассажира (нахамил / не пришёл / испортил машину / не заплатил / небезопасно / другое).
- **Лестница наказаний** (честно, прозрачно, с человеком):
  | Ступень | Когда | Что |
  |---|---|---|
  | 🟡 Подсказка | лёгкая жалоба / рейтинг просел | «будь повнимательнее», без наказания |
  | 🟠 Меньше заказов | рейтинг < 4,6 | ниже в подборе; вернуть хорошими поездками |
  | 🔴 Пауза такси | много жалоб / грубое | блок такси (попутка работает), снимается после разбора |
  | ⛔ Разбор у Александра | SOS / высадил / опасное / обман | заявка сразу, личности видит только модератор; решение с правом апелляции |
- **Только такси наказываем строго; попутка — мягче; SOS/безопасность — железно всегда.**

## 11. 🚀 Стратегия запуска (у Александра сильный охват: пост 20k просмотров за 2 дня)
Риск теперь не «нет спроса», а «пусто в конкретном городе / сервер ляжет / публичный провал». Поэтому «сразу на всю РБ», но **умно**:
1. **Техника готова ДО залпа:** мониторинг (Sentry), масштаб (managed-БД + нагрузочный тест Locust), бэкапы. ⚖️/🧭
2. **Тихий бета-старт** (свои + первые водители, 3–7 дней, чиним) — публичному человеку нельзя «в прямом эфире».
3. **Водителей — первыми:** охват сначала на водителей («0% комиссии, застолби город»), потом пассажиры. Сначала предложение, потом спрос.
4. **Попутка — на всю РБ сразу** (терпит редких водителей). **Такси — по городам** (нужна плотность) через **переключатель такси по регионам** (не только глобальный).
5. **Медиа-залп** → трафик через **«ранний доступ / список ожидания»** волнами (город за городом).
6. Расширяем такси по мере плотности.

**Новое для кода (из запуска):**
- Переключатель такси **по городам/регионам** (не только глобальный флаг).
- **«Ранний доступ / список ожидания»** — собирать номера, пускать волнами.
- Экран **«Скоро в вашем городе»** вместо пустоты («оставь номер — сообщим»).
- Усилить набор водителей (реферал водителей уже есть).
