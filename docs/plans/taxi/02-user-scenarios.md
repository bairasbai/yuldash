# Матрица пользовательских сценариев такси

[Индекс](00-index.md) · [Договоры](01-sources-states-contracts.md) · [Встречные трассы](04-validation-and-handoff.md)

Все строки ниже — **целевые проверяемые сценарии**, не список доказанных возможностей или выполненных тестов. Их исходный исполнительский результат — NOT_EXECUTED. Частичные локальные проверки из протокола не принимают целую строку автоматически. Текущая приёмка — только в `docs/audit-blocks.md`. Новые TP/TD/TX сохраняют связь с прежними ID, а не заменяют их.

Заявленный состав: **165 сценариев: 70 пассажира, 63 водителя, 32 сквозных**. Число отражает строки плана, а не покрытие тестами.

Условия каждой строки: свой тестовый аккаунт/заказ; изолированный сервер/провайдер; никакой регистрации случайных живых поездок. Права, отказ сети, двойное действие, неизвестный исход, смена владельца и доступность проверяются по применимости. Группа E2E `04` означает `TAXI-E2E-04`. Для TP/TD обе платформы обязательны; для TX — явно указанная пара и модификаторы ниже. Ожидаемый результат должен подтверждаться одновременно интерфейсом и авторитетным итогом сервера.

## Обязательные модификаторы и граница полноты

Для каждой денежной/маршрутной команды: normal; отказ до исполнения; потеря ответа после доказанного commit; повтор/два клиента; смена аккаунта до ответа; поздний ответ; восстановление приложения. Для чтения: loading/empty/first error/retry/stale/offline/401/403/404/409/5xx по применимости. Для каждого TS: RU/BA × темы × узкий/широкий × крупный текст/клавиатура/скринридер. Модификаторы — план комбинаций, не автоматически выполненное декартово произведение и не число уникальных тестов.

Точный executable test получает ID сценария + суффикс платформы/варианта, SHA, данные, команду и первичный журнал. Новые проверки не уменьшают обязательные подусловия TAXI-E2E. Заказ для другого уже существует: Android InstantOrderScreen.kt:2999/3142, PWA InstantOrderScreen.tsx:503/983, backend routers/instant.py:492/579; его положительный путь — TX29. Для отдельно не допущенных корпоративных поездок, аэропортовой очереди или цепочки заказов проверяется честная недоступность, а включение требует отдельного решения. Возврат в такси — финансовый возврат или обратный маршрут; судьбу посылки и правила COURIER не переносим сюда.
