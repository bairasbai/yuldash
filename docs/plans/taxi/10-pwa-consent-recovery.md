# Подтверждение цены такси и восстановление заказа в PWA

Локальный режим охватывает первый заказ такси «сейчас» в экране `/taxi`. Для него нужны [подтверждение цены](07-initial-price-consent-api.md), [проверка результата](08-price-consent-result-api.md) и [завершение попытки](09-price-consent-close-api.md) на одном сервере. Заказ «на время» использует свой обычный API.

## Запуск тестового режима

По умолчанию сайт использует прежний путь. Для пилота при сборке задаются `VITE_TAXI_QUOTE_CONSENT_LOCAL=1` и явный `VITE_API_BASE`. Сайт и API должны работать по HTTP(S) на loopback-адресах. Если режим запрошен с неподходящим адресом, экран такси останавливается до запроса координат и обращения к API заказов.

Пассажир видит стоимость, скидку и итог, затем подтверждает показанную сумму. При изменении условий нужна новая оценка. При неоднозначном ответе интерфейс сохраняет барьер для нового заказа. Тело исходного запроса остаётся в памяти открытой вкладки. Локальная запись восстановления содержит непрозрачный ключ попытки, версию формата, поколение входа и идентификатор тестовой среды. Маршрут, адрес, телефон и токены в эту запись не попадают.

## Восстановление после обрыва связи

После перезагрузки экран такси сначала проверяет сохранённые попытки текущего входа. Пассажир может проверить результат или завершить попытку, даже если история поездок недоступна или город прекратил принимать новые заказы. Запрос геолокации и поиск активной поездки начинаются после снятия последней записи и нажатия «Продолжить». Фоновое обновление страницы, смена вкладки и потеря ответа сами по себе не отправляют команду завершения.

Если попыток несколько, пассажир выбирает одну из списка. Проверка результата и завершение относятся к выбранной попытке. Башкирская подпись «Ынтылыш № 3» ожидает проверки носителем.

| Ответ сервера | Что делает сайт |
|---|---|
| Заказ создан (`committed`) | Загружает карточку с текущей авторизацией. Проверяет заказ и открывает его с актуальной суммой. Пока получить карточку не удалось, сохранённая попытка остаётся на месте. |
| Закрыто, заказ не создан (`closed/not_created`) | Снимает только запись этой попытки. Следующий заказ требует новой оценки и явного согласия пассажира. |
| Заказ ранее создавался, карточка недоступна (`retired/created_unavailable`) | Сообщает о прежнем заказе, сохраняет запись попытки и предлагает проверить свои поездки. |
| Историю подтвердить не удалось (`unknown/unverified`) | После ответа на явное завершение сообщает, что позднее создание по этому ключу заблокировано. История остаётся неизвестной. Простая проверка результата (`unknown` из API08) оставляет попытку открытой для дальнейшей проверки. |
| Нет ответа или формат некорректен | Сохраняет запись и даёт пассажиру возможность явно повторить проверку. |

Выйдя из аккаунта, пассажир завершает текущую сессию. Открытую попытку нельзя перенести на другой вход или устройство по данным этого пилота. Старый локальный маркер без ключа также не позволяет автоматически восстановить заказ. Работу Android и доставку уведомлений на устройство проверяют отдельно.
