## 1. Что получит человек
Гульнара доехала из Сибая в Акъяр, пришло «Оцени поездку». **Было:** искать поездку и листать до звёзд — многие смахивали уведомление. **Стало:** две кнопки. «5 ★» не ставит сразу: уведомление спрашивает «Поставить 5 ★?» — «Да» / «Отмена» (случайное касание ничего не меняет). «Есть замечания» открывает поездку, где звёзды не выбраны и есть метки («опоздал», «грубил»). После «Да»: «Отправляем…», «Оценка 5 ★ принята», «Изменить». Нет связи — «Сохранили. Отправим, когда откроешь приложение со связью» и «Отменить». Засчитано только после ответа сервера.

Кнопок нет, если оценить нельзя (прошло 60 дней, аккаунт на паузе). На заблокированном телефоне оценка не ставится при любой настройке шторки: «Разблокируй телефон, чтобы оценить». Стоящую оценку уведомление не перезапишет; при смене входа не уйдёт. Ночное напоминание придёт утром. На сайте то же в Chrome; без кнопок нажатие открывает поездку.

## 3. Что сделать
### Сервер `[RS-13А]`
1. `rating_service.py`: `apply_rating(…, only_if_new=False)` возвращает `RatingResult(avg, count, kept, my_stars)`; вызовы `family.py:660`, `instant.py:930` читают `.avg/.count`, поведение прежнее. При `only_if_new` и существующей оценке — ничего не писать и **завершить транзакцию** (`rollback`: иначе держатся advisory-lock и блокировка SQLite). Рядом `rating_allowed_fast(user_id, happened_at, suspended_ids, now)` — окно и пауза без базы.
2. `RateIn.from_notification: bool = False`: оценка уже есть — 200 `{ratee_id, rating, count, kept: true, my_stars}` без изменений; проверки 403/409/окно/пауза прежние, ошибки `herr(…, code=…)` по RS-01 (клиенты ветвят по `code`). Журнал: `[RATE] src=notification|app stars=N` (без id и имён).
3. `rate_reminder.py`, только `booking`: (а) раз за проход `suspended_user_ids(session)` и `rating_allowed_fast` (нельзя — стороне не напоминать); (б) в тихие часы пропускается только сервис `booking` (`_is_quiet_hour()`, `services.py:674`): бронь не помечается, утренний проход отправит; (в) **смена типа:** `data={"type":"booking_done","id":<бронь>,"rate":"1","rate_role":"passenger|driver","rate_until":<выезд + 60 дней, секунды>}` вместо `booking`: Android открывает завершённую поездку, сайт — `/trip/{id}`. Центр уведомлений (`ref_kind="booking"`), такси и доставку не трогать.
4. `_send_web_push`: при `rate=1` — `actions` («5 ★», «Есть замечания» на языке получателя) и `rate:{booking_id, recipient_user_id, until}`.
### Сайт `[RS-13Б]`
5. `push-sw.js`: `actions` из payload (≤ `Notification.maxActions`). «5 ★» — черновик в IndexedDB `yuldash-rate-draft` (бронь, звёзды, `recipient_user_id`, время) и переход на `/trip/{id}` **без параметров** (чужая ссылка оценку не поставит). «Есть замечания» и браузеры без кнопок — обычный переход.
6. `rateDraft.ts` + `ActiveTripScreen.tsx`: при открытии завершённой брони прочитать и удалить черновик; если бронь совпала, `recipient_user_id` — текущий пользователь и возраст ≤ 10 минут, спросить «Поставить 5 ★?» **Да / Отмена** (как W1-FIN-27) → `rateBooking(…, fromNotification)`; `kept` — «Оценка уже стоит: {my_stars} ★». Без сети очереди нет — обычные звёзды. `clearSessionData` стирает базу `yuldash-rate-draft`; тест — в `tests/run.mjs`.
### Android `[RS-13В]`
7. `FcmService`: при `rate=1`, `booking_done`, `id>0`, `now<rate_until` — два `NotificationCompat.Action`: «5 ★» (`getBroadcast`, явный компонент, `FLAG_IMMUTABLE`) и «Есть замечания» (`getActivity`, intent `booking_done`: трамплин через receiver запрещён с Android 12). Блокировка: `VISIBILITY_PRIVATE` + публичная версия без кнопок; `setAuthenticationRequired(true)`, если есть в текущей `androidx.core` (версии не менять, §10).
8. `RateNotificationAction` (`BroadcastReceiver`, `goAsync`), два шага. «5 ★»: вход выполнен, `recipient_user_id == myUserId()`, бронь > 0 и **`KeyguardManager.isDeviceLocked()`** — заблокирован: ничего не писать, «Разблокируй телефон, чтобы оценить»; иначе «Поставить 5 ★?» с «Да»/«Отмена» (на диск ничего). «Да»: проверки заново, **черновик** `OutboxAction(kind="rate", payload={stars, owner, until})` в `Outbox` ДО сети, «Отправляем…», `Outbox.flush` (общий замок), таймаут ≤ 8 с. Исход: 200/`kept` → из очереди, «Оценка 5 ★ принята» + «Изменить»; сеть/408/429/5xx → остаётся, «Сохранили…» + «Отменить»; `onRefused` для `rate` (403/404/409) → «Эту поездку оценить уже нельзя».
9. `Outbox`/`ApiClient`: вид `"rate"` живёт **до `until`**, а не 6 часов (`TripPass.kt:493`), просроченный выбрасывается; ветка `"rate"` в `sendQueuedAction` со сверкой `owner == myUserId()`; `count` (`:371`) вид `rate` не считает; `rateBooking(…, fromNotification)`. Манифест: `<receiver android:name=".data.RateNotificationAction" android:exported="false" />`.
