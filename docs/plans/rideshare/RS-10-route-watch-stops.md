## 1. Что получит человек
Гульнара живёт в Ургазе, ей нужно в Акъяр, поездок нет — она подписалась на «Ургаза → Акъяр». Рамиль публикует «Сибай → Акъяр через Ургазу». Сейчас Гульнара не узнает: приложение сверяет только начало и конец маршрута, а Ургаза — остановка посередине. «Каждый понедельник» дал бы сообщение лишь про первый рейс.

Теперь подписка работает как поиск: что нашёл бы поиск, о том придёт сообщение («садишься в: Ургаза»). Про серию — одно сообщение «рейсов: 5». На сайте кнопка «Следить за маршрутом» стоит там, где поездок не нашлось. В «Подписках» видно, когда было последнее сообщение и включены ли уведомления на телефоне.

## 3. Что сделать
### Сервер (`backend/`)
1. **S1 (совпадение).** `route_watch_fit(session, watch, ride, entry)` в `services.py`: `stop_search.variants` + `stop_searchable` + `route_fit(ride, fv, tv, entry, …)`; для `direction == "both"` ещё раз наоборот. `entry = request_snapshot(settlements_snapshot(session))` один на рассылку; вердикт кешируется по (откуда, куда, направление, вид маршрута). `_city_keys` остаётся для `notify_request_watchers` (заявки — вне плана).
2. **S2 (серия).** `notify_route_watchers(session, ride, siblings: Sequence[Ride] = ())` — «братья» приходят **явным списком** от вызывающего (RS-09Б: пачка и копии `recurrence`); параметр вводит тот из RS-09Б и RS-10, кто вливается первым. Не передан — запас: активные рейсы того же водителя с теми же `from_city`, `to_city`, `waypoints`, `category` и `created_at` в пределах 10 с. Для подписки берутся рейсы, подошедшие по S1 и по `watch_date` (местный день). Подошёл хоть один — **одно** оповещение, ref — самый ранний.
3. **S3 (кому нельзя).** К существующим (свой рейс, `may_be_notified`) добавить: водитель на паузе (`safety_logic.suspended_user_ids`), рейс не активен, уже уехал и **мест нет — так же, как в ленте**. После RS-02 `seats_left` — минимум по всем участкам и отсеял бы подписчика на свободный хвост, поэтому участок берётся из `Fit` (`matched_*`, правило предвыбора карточки): однозначен → `ride_seats.free_on(участок) ≥ 1`, иначе `ride_seats.max_free ≥ 1` (RS-02, п. 8). До RS-02 — `seats_left > 0`.
4. **S4 (текст).** RU: «Появилась поездка» / «Появились поездки»; тело `«{откуда} → {куда}»` + « · садишься в: {matched_stop}» / « · выйдешь в: {matched_dropoff_stop}» при совпадении по остановке + « · рейсов: N», если подошло больше одного. Язык пуша — по `User.language` (один запрос на всех); BA — черновик исполнителя. Ночью (`_is_quiet_hour`) запись в «Уведомлениях» есть, пуша нет, а сутки (`last_notified_at`) тратятся — **намеренно**: человек увидит запись утром, второй пуш за сутки не нужен.
5. **S5 (без дублей).** Уже есть `Notification(user_id, type="route_watch", ref_kind="ride", ref_id=<рейс>)` — пропустить; проверка **одним запросом** по всем рейсам (`ref_id IN (…)`, `user_id IN (…)`). Повторный вызов на тот же рейс (в т.ч. из правки остановок) ничего не шлёт.
6. **S6 (статус).** `RouteWatchOut` + `last_notified_at`, `push_channels{app, web}` (есть `DeviceToken` / `WebPushSubscription`), `quiet_from`, `quiet_to` (`settings.quiet_hours_*`, 0 = выключены). Только известное серверу: запись в центре — всегда, пуш — если есть устройство; «дошло» не обещаем.
7. **S7 (ввод).** `POST /route-watch`: место проходит `stop_searchable` и ≥ 2 букв, иначе `herr(400, "Название места — буквами, без цифр", <ba: черновик>, code="watch_place_invalid")` (RS-01).

## 9. Риски и границы
- «Как в поиске» для голых названий подстрочное; защита — S7 и «раз в сутки». Не входит: заявки водителя (`notify_request_watchers`), подписка на день, автоотписка после брони, подтверждение доставки.
- **Дыра с RS-15 (правка остановок).** Рассылка вызывается только при публикации. Кто вливается **вторым** из RS-10 и RS-15, тот добавляет в `edit_ride` (`rides.py`) вызов `notify_route_watchers` после правки остановок (после `commit`, затем `session.refresh`) и тест: «правка добавила Ургазу → подписчик Ургаза→Акъяр оповещён раз, повторная правка — без второго». Первый ничего не добавляет.
- Общие файлы (`MapScreen.kt`, `HomeScreen.tsx`, `tests/run.mjs`) — по очереди с RS-11, RS-12. Приватность: в тексте только названия мест; «братья» — рейсы того же водителя.
- **Мозг:** `architecture.md` — подписка сверяется через `route_fit`; `decisions.md` — «сутки, потраченные ночью» намеренно, статус только известного серверу; `tasks.md` — BA-черновики; `lessons.md` — подписка расходилась с поиском (концы маршрута вместо `route_fit`).
