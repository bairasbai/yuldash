## 1. Что получит человек
Гульнара живёт в Ургазе, ей нужно в Акъяр, поездок нет — она подписалась на «Ургаза → Акъяр». Рамиль публикует «Сибай → Акъяр через Ургазу». Сейчас Гульнара не узнает: приложение сверяет только начало и конец маршрута, а Ургаза — остановка посередине. А «каждый понедельник» дал бы сообщение лишь про первый рейс.

Теперь подписка работает как поиск: что нашёл бы поиск, о том придёт сообщение («садишься в: Ургаза»). Про серию — одно сообщение «рейсов: 5». На сайте кнопка «Следить за маршрутом» стоит там, где поездок не нашлось. В «Подписках» видно, когда было последнее сообщение и включены ли уведомления на телефоне.

## 3. Что сделать
### Сервер (`backend/`)
1. **S1 (совпадение).** `route_watch_fit(session, watch, ride, entry)` в `services.py`: `stop_search.variants` + `stop_searchable` + `route_fit(ride, fv, tv, entry, …)`; для `direction == "both"` ещё раз наоборот. `entry = request_snapshot(settlements_snapshot(session))` один на рассылку; вердикт кешируется по (откуда, куда, направление, вид маршрута). `_city_keys` остаётся для `notify_request_watchers` (заявки — вне плана).
2. **S2 (серия).** «Братья» рейса — активные рейсы того же водителя с теми же `from_city`, `to_city`, `waypoints`, `category` и `created_at` в пределах 10 с. Для подписки берутся братья, подошедшие по S1 и по `watch_date` (местный день). Подошёл хоть один — **одно** оповещение, ref — самый ранний. Работает для `recurrence` и для пачки RS-09 (рассылку она зовёт один раз после создания всех).
3. **S3 (кому нельзя).** К существующим (свой рейс, `may_be_notified`) добавить: водитель на паузе (`safety_logic.suspended_user_ids`), рейс не активен, мест нет, уже уехал.
4. **S4 (текст).** RU: «Появилась поездка» / «Появились поездки»; тело `«{откуда} → {куда}»` + « · садишься в: {matched_stop}» / « · выйдешь в: {matched_dropoff_stop}» при совпадении по остановке + « · рейсов: N», если подошло больше одного. Язык пуша — по `User.language` (один запрос на всех); BA — черновик исполнителя.
5. **S5 (без дублей).** Есть `Notification(user_id, type="route_watch", ref_kind="ride", ref_id=<самый ранний>)` — пропустить: повторный вызов (в т.ч. из правки остановок RS-15) на тот же рейс ничего не шлёт.
6. **S6 (статус).** `RouteWatchOut` + `last_notified_at`, `push_channels{app, web}` (есть `DeviceToken` / `WebPushSubscription`), `quiet_from`, `quiet_to` (`settings.quiet_hours_*`, 0 = выключены). Только известное серверу: запись в центре — всегда, пуш — если есть устройство; «дошло ли» не обещаем.
7. **S7 (ввод).** `POST /route-watch`: место проходит `stop_searchable` и ≥ 2 букв, иначе `HTTPException(400, {ru:"Название места — буквами, без цифр", ba:<черновик>, code:"watch_place_invalid"})`. Дубль обновляет, `DELETE` прежний.
