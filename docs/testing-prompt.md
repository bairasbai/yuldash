## Заметки к промту (почему именно так)

- **Ограничение API** — фактическое условие задано в BilingualComposeTest.kt через @SdkSuppress(maxSdkVersion = 36), не через общий @Ignore. Подбирай поддерживаемый доступный AVD; более новый SDK не превращает пропуск в PASS.
- **Кириллица в консоли** — Windows-консоль cp1251, `uiautomator dump` содержит `→`/кириллицу. Парсить bounds через `python` с `export PYTHONIOENCODING=utf-8`, иначе `UnicodeEncodeError`.
- **Файлы ключей** — неприкосновенны по §11 AGENTS.md; сборка не разрешает их читать/копировать/связывать ссылками. Нужные параметры тестового клиента задаются явно, изоляция и фактический адрес подтверждаются отдельно.
- **Тестовый API и вход** — подготовка токена синтетического участника позволяет проверить API, но обходит экранный вход. Не выдавать её за успешную авторизацию через приложение.
- **Локальное реле координат** — сценарий своего сервера с эмулятором проверяет лишь этот путь. Он не заменяет живые два телефона, доставку push и отдельную независимую приёмку всего режима.
