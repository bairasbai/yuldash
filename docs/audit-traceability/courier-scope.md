# Фиксированный состав приёмки доставки

Аудит `COURIER-E2E-20261023`. Это требования, а не второй реестр статусов.
Текущие статусы остаются в [едином реестре](../audit-blocks.md), B03/B04 и соответствующих PATH.
Состав выделен из действующих материалов по поручению Александра 23.10.2026;
исторические QA/PATH/денежные ID сохраняются и не становятся новыми PASS.
Каждое подусловие ниже обязательно; число пунктов само по себе не доказывает полноту.
Для доставки обязательны отправитель, попутный перевозчик, профессиональный курьер и получатель.

## COURIER-E2E-01 — Попутная доставка

Обязательное требование (`must`, `P1`): Отправитель создаёт посылку настоящей пустой формой → попутный перевозчик находит/принимает → забирает → вручает полученным кодом → обе стороны видят доставку. Обе пары Android/PWA. Попутному перевозчику профессиональная заявка не требуется.

Источники при выделении состава: `docs/audit-blocks.md:57–58,404–420; docs/audit-role-journeys.md:22–23,44`. Прежние ID: **PATH-06/07, QA-B04-001/002**. Номера строк относятся к моменту составления; ищи также по ID и смыслу.

## COURIER-E2E-02 — Профессиональная доставка

Обязательное требование (`must`, `P1`): Заявка → решение/допуск → линия → созданный заказчиком заказ → получение или покупка → вручение → расчёт. Начало не подменяется подготовленными approved/online.

Источники при выделении состава: `docs/audit-blocks.md:59; docs/audit-role-journeys.md:24,45`. Прежние ID: **PATH-08, B04**. Номера строк относятся к моменту составления; ищи также по ID и смыслу.

## COURIER-E2E-03 — Покупка и расчёт

Обязательное требование (`must`, `P0`): Согласованный бюджет покупки, ошибка суммы/сети и повтор с сохранённым вводом, платное ожидание, доставка/возврат, комиссия/ручное подтверждение и состав счёта проверены без двойного зачёта. Цена возврата показана до заказа. Чужое фото не меняет назначение и не останавливает ожидание. Реальные деньги не отправляются.

Источники при выделении состава: `docs/audit-role-journeys.md:45–46,54–55; docs/audit-taxi-courier-recovery-2026-09-19.md:12,24; docs/architecture.md:3531–3532,4155–4161`. Прежние ID: **WALLET01, BE35; BE06/BE23 по своей области**. Номера строк относятся к моменту составления; ищи также по ID и смыслу.

## COURIER-E2E-04 — Отказ и возврат

Обязательное требование (`must`, `P1`): Отказ, недоступность другой стороны, неудачная попытка вручения и возврат доходят до правильного окончательного состояния returned. Ответственность перевозчика сохраняется, координаты прекращаются вовремя; returning не выдаётся за обычную доставку.

Источники при выделении состава: `docs/audit-blocks.md:58–59,105,424,1180; docs/audit-role-journeys.md:22,45; docs/architecture.md:3531,4386–4390`. Прежние ID: **PATH-06/07/08, B04**. Номера строк относятся к моменту составления; ищи также по ID и смыслу.

## COURIER-E2E-05 — Разрешённый спор

Обязательное требование (`must`, `P0`): Форма спора → отправка → разбор → результат участникам. Доступ сохраняется после разрешённых конечных исходов. Открытие формы не заменяет отправку и разбор.

Источники при выделении состава: `docs/audit-blocks.md:59,63,105; docs/audit-courier-completion-2026-09-19.md:8,14–16,40`. Прежние ID: **PATH-08/12, B04/B08**. Номера строк относятся к моменту составления; ищи также по ID и смыслу.

## COURIER-E2E-06 — Итог и оценка

Обязательное требование (`must`, `P1`): Delivered/returned/canceled показывают только разрешённые действия; квитанция, своя оценка и повторный вход восстанавливаются. У canceled квитанция возвращает 409 по текущему договору; последние десять записей не называются полной историей. Второй голос доставки запрещён; при неизвестном результате сначала читается сервер.

Источники при выделении состава: `docs/audit-courier-completion-2026-09-19.md:10–18; docs/audit-parcel-rating-recovery-2026-09-19.md:9,13–18`. Прежние ID: **PATH-06/07/08**. Номера строк относятся к моменту составления; ищи также по ID и смыслу.

## COURIER-E2E-07 — Сеть и конкуренция

Обязательное требование (`must`, `P0`): Потеря сети/ответа, повтор, перезапуск/смерть процесса и конкурентные действия не дублируют заказ, принятие, вручение, сумму или оценку. Поздний ответ не переносит результат в другую посылку/аккаунт. Совмещение с такси проверяется по существующей политике.

Источники при выделении состава: `docs/audit-blocks.md:420,424; docs/audit-parcel-rating-recovery-2026-09-19.md:15–18; docs/audit-role-journeys.md:46,63`. Прежние ID: **B04, PATH-06/07/08**. Номера строк относятся к моменту составления; ищи также по ID и смыслу.

## COURIER-E2E-08 — Получатель и приватность

Обязательное требование (`must`, `P0`): Настоящая клиентская ссылка получателя → разрешённое отслеживание → код → вручение → закрытие живых координат. Неверный код не завершает заказ. Чужие посылки/медиа/ссылки, смена входа и поздние события защищены; SOS имеет правильный контекст.

## COURIER-E2E-09 — Экран и два языка

Обязательное требование (`must`, `P1`): Заявленный полный набор экранов четырёх участников: RU/BA × темы, размеры/крупный текст, загрузка/пусто/ошибка/повтор, разрешения, доступность, Canon и анимации. BA подтверждает носитель; итог — свежий независимый принимающий.

## COURIER-E2E-10 — Телефоны и выпуск

Обязательное требование (`must`, `P0`): Два физических телефона и настоящий сервер: реальные GPS/MapKit/уведомления в фоне, получатель и закрытие доступа, SOS. Реальная доставка сообщения и физическая передача не подменяются API. Согласованы версии Android/сервера/PWA; выпуск отдельно разрешает Александр.
