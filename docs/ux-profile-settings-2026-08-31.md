## 1. Вердикт

**Оставлять как есть нельзя.** Экраны работают — ничего не падает, тёмная тема и башкирский
в порядке. Ломается другое: **человек не находит то, за чем пришёл.**

Три вещи, из-за которых это происходит:

1. **46 строк в одном списке** — восемь смахиваний сверху донизу, без разделения на «нужное
   мне» и «нужное кому-то другому».
2. **Выход из аккаунта, тёмная тема и размер текста спрятаны за строкой «Уведомления и карта».**
   Название не говорит о содержимом.
3. **Пассажир видит всё**: кабинет водителя, режим курьера, «Мой бизнес», «Кабинет рекламы».
   Скрыты по роли только две админские строки из сорока шести.

## 6. Предлагаемая структура профиля

Принцип: **сверху то, чем человек пользуется каждую неделю; ниже — то, что настраивают
один раз; чужие роли не показываем вовсе.**

```
┌─ Карточка профиля (имя, город, «профиль подтверждён»)
│
├─ [если не заполнено] Укажи город — одной строкой, не карточкой
│
├─ ЧАСТО НУЖНОЕ                     ← новое, 3 строки максимум
│   Крупные кнопки                  ← бывший «Простой режим», поднят наверх
│   Мои поездки
│   Настройки
│
├─ ДЕНЬГИ                            ← видно, только если человек водитель/курьер/партнёр
│   Мой заработок
│   Кошелёк
│   Поднять поездку
│
├─ БЕЗОПАСНОСТЬ
│   Доверенные контакты
│   Кто мне доверяет
│   SOS и скрытый телефон
│
├─ СЕРВИСЫ
│   Скидки по пути
│   Посылки
│   Промокод
│
├─ [если водитель] КАБИНЕТ ВОДИТЕЛЯ   ← одна строка вместо четырёх разбросанных
├─ [если курьер]   РЕЖИМ КУРЬЕРА
├─ [если партнёр]  МОЙ БИЗНЕС
├─ [если админ]    КАБИНЕТ АДМИНА     ← перенести из настроек сюда
│
├─ Позови своего                      ← рефералка вниз: это не то, зачем открывают профиль
└─ Аккаунт: выйти / удалить
```

**Что меняется по числам:** для обычного пассажира список сокращается с 46 строк
примерно до 16 — три смахивания вместо восьми.

**Обоснование каждого переноса:**

| Перенос | Почему |
|---|---|
| «Простой режим» наверх и переназвать | Тому, кому нужны крупные кнопки, нельзя давать пять смахиваний мелким шрифтом |
| Рефералка вниз | Сейчас занимает треть первого экрана. Профиль открывают не за ней |
| Роли под условием | Пассажир не должен читать про режим курьера, чтобы дойти до своих поездок |
| «Кабинет админа» в профиль | Он и так виден только админу; в настройках его никто не ищет — я сам не нашёл |
| Выход и удаление в конец, вместе | Оба про «уйти», их место рядом и внизу, а не в разных экранах |

## 9. Поправка: третья находка не подтвердилась

«Ночного режима уведомлений нет вовсе» — **неверно**. Он есть, включён по умолчанию
и сделан аккуратнее, чем я бы сделал:

- тишина с 22:00 до 7:00 по местному времени (`quiet_hours_from` / `quiet_hours_to`);
- молчит только звук — запись в Центре уведомлений остаётся, человек увидит её утром;
- срочное проходит всегда: беда, идущая поездка, сообщение от попутчика, деньги,
  статусы доставки и такси (`_LOUD_AT_NIGHT` в `services.py:479`);
- часовой пояс учтён (Уфа UTC+5).

**Почему я не нашёл.** Искал по словам `quiet_hours`, «тихие часы», «не беспокоить» —
а функция называется `_is_quiet_hour`, без `s` на конце, и мой шаблон её не поймал.
Вывод «нет вовсе» я сделал по пустому результату поиска, не проверив путь отправки пушей.

**Правило на будущее:** прежде чем писать «такого нет», пройти путь целиком —
от кнопки до места, где событие реально отправляется. Пустой grep это не доказательство.

**Что осталось и сделано:** человек о ночной тишине не знал. Теперь под тумблером
уведомлений написано, что ночью Юлдаш не звонит по мелочам, а срочное проходит всегда.
Точные часы намеренно не называем — они меняются в настройках сервера, и число
в приложении быстро стало бы враньём. Ключи задокументированы в `backend/.env.example`.
