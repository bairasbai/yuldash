## Изменение

OfflineMigration.kt сохраняет в plain журнал с точным снимком переносимых строк. Затем одним подтверждённым commit копирует их в secure; затем одним подтверждённым commit удаляет только исходные ключи и журнал. Другие защищённые паспорта и служебные поля plain не удаляются.

Пока любой этап не завершён, изменения блокируются: save/enqueue/remove возвращают false, updateBoardingCode не меняет паспорт, flush ничего не отправляет. Данные снимка доступны для чтения даже если неудачный commit уже удалил их из памяти настроек. Повторный init того же процесса использует также сохранённый в памяти снимок; новый процесс — журнал с диска. Повреждённый журнал не считается отсутствующим и не даёт разрешения записывать.

Операции TripPassStore теперь сериализованы одним монитором, как изменения Outbox. Удаление отдельного паспорта возвращает результат подтверждённой записи; это не решает отдельный случай удаления при недоступном secure после ранее завершённого переноса.

Выход сначала закрывает доступ к незавершённому снимку. После подтверждённой очистки plain с отметкой secure_clear_pending журнал забывается; недоступный secure очищается при возвращении. Если первая запись выхода отказала, в текущем процессе снимок остаётся закрытым до повторной очистки. Гарантия после перезапуска при отказе этой первой записи — отдельный открытый случай.

## Намеренное изменение поведения при отказе копирования

Ранее после отказа secure-копии тесты разрешали новые записи в plain. Теперь начатый перенос временно блокирует изменения, чтобы промежуточная secure-копия не воскресила удалённый паспорт. Два теста OfflineMigrationWriteTest обновлены под этот явный контракт: старое сохранено, новое не объявляется принятым, после успешного повторного init запись снова работает. Это не утверждение о непрерывной работе при поломанном хранилище. UI обрабатывает false для очереди. Фоновый saveTripPass и вызовы remove пока игнорируют результат: уведомление о несохранённом паспорте и повтор отложенного удаления остаются отдельной задачей; нельзя утверждать, что все отказы видны человеку.
