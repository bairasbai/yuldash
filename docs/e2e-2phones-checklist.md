# 📱 E2E-чеклист на 2 телефона — 15 минут (Александру)

> Главный оставшийся гейт качества. Ядро — живая стрелка попутчика, пуши, заказ такси —
> НИКОГДА не проверялось на реальных телефонах, только в коде и на эмуляторе. Пройди по шагам
> с двумя телефонами и отметь галочки. Что не так — напиши агенту номер шага и что увидел.

---

## 0. Откуда взять приложение

**Готовый APK уже собран** (12 августа 2026):

```
android/app/build/outputs/apk/debug/app-debug.apk
```

Перекинь файл на оба телефона (Telegram самому себе, кабель, флешка) и открой — Android
предложит установить. Понадобится разрешить «установку из неизвестных источников».

⚠️ **Раньше здесь была мина.** Отладочная сборка по умолчанию ходит на адрес `10.0.2.2` —
это «мой компьютер» глазами эмулятора, и на настоящем телефоне такого адреса нет: приложение
ставится, открывается и молча висит в «нет связи». Собранный APK выше уже смотрит на боевой
`yulbash.ru`. Если будешь пересобирать сам — только так:

```bash
cd android && YULDASH_DEBUG_API_BASE_URL=https://yulbash.ru ./gradlew.bat :app:assembleDebug
```

Проверить, куда смотрит собранный APK, можно этой командой (должно показать `https://yulbash.ru`):

```bash
grep -r YULDASH_API_BASE_URL android/app/build/generated/source/buildConfig/debug/
```

## Подготовка
- [ ] Два телефона, на обоих установлен APK.
- [ ] Интернет на обоих.
- [ ] Дальше телефоны зовём **A** и **B**.

## 1. Вход (обе стороны)
- [ ] A: вошёл через Telegram (код из бота) → попал на карту.
- [ ] B: вошёл через Telegram (другой аккаунт) → попал на карту.
- ✅ **Прошло:** оба на главном экране, ничего не упало.

## 2. Попутка: A публикует, B бронирует
- [ ] A: «Создать поездку» → маршрут (например, Баймак → Сибай), время, места, цена.
- [ ] A: под маршрутом появилась (или НЕ появилась) карточка погоды — смотри шаг 9.
- [ ] A: опубликовал.
- [ ] B: видит поездку A в «Ближайших» → открывает → «Забронировать».
- [ ] A: получил **пуш** «Новая бронь» — даже если приложение свёрнуто. ← **проверка пушей №1**
- ✅ **Прошло:** бронь создалась, у B появилась поездка, A получил пуш.

## 3. Живая стрелка — самое важное
- [ ] Оба открыли экран активной поездки.
- [ ] A идёт или едет с телефоном: **B видит стрелку A, и она движется по дороге плавно**.
- [ ] У B «≈ … осталось» уменьшается по мере движения.
- [ ] A: в шторке уведомлений висит «Юлдаш — поездка идёт».
- ✅ **Прошло:** стрелка едет плавно, время живое, уведомление висит.

> Это единственное место, где нужны именно два живых телефона. В отладочной сборке есть
> кнопка «▶ Симуляция» — фейк-попутчик едет по маршруту, но настоящую проверку она не заменяет.

## 4. Язык уведомления
- [ ] Переключи на одном телефоне язык на башкирский (Профиль → Настройки → Язык).
- [ ] Зайди в активную поездку: уведомление сервиса стало башкирским.
- ✅ **Прошло:** уведомление сменило язык.

## 5. Чат
- [ ] A пишет → B получает (в чате и **пушем**, если свёрнуто). ← **проверка пушей №2**
- [ ] B отвечает → A получает.
- ✅ **Прошло:** сообщения ходят в обе стороны.

## 6. Код посадки и «та ли машина»
- [ ] B видит код посадки; A видит тот же код.
- [ ] Рядом с кодом видно машину и **госномер** (если водитель их заполнил).
- ✅ **Прошло:** коды совпали, номер виден.

## 7. Такси (если включено в твоём городе)
- [ ] B: вкладка «Такси» → указал куда → видит цену **до** вызова.
- [ ] A (водитель, если у него одобрена заявка таксиста): включил «Я на линии».
- [ ] B: вызвал → A получил предложение заказа **пушем** на погашенном экране. ← **проверка пушей №3**
- [ ] A принял → у B пошёл живой статус и позиция машины.
- ✅ **Прошло:** заказ дошёл до водителя и обратно.

> Такси включается отдельно и требует ИП (580-ФЗ). Выключено — этот шаг пропусти, это не поломка.

## 8. Обновление жестом
- [ ] На любом списке (мои поездки, отклики, кабинет водителя) потяни экран вниз.
- ✅ **Прошло:** появляется крутилка, список обновляется.

## 9. Погода на маршруте
- [ ] Открой создание поездки, укажи маршрут.
- ✅ **Прошло:** если сейчас гололёд/метель/туман — карточка появилась; если погода обычная —
  карточки нет. **Отсутствие карточки в хорошую погоду — это правильно, а не поломка.**

## 10. SOS
- [ ] B: кнопка SOS → открылся экран экстренной связи, видно геопозицию, кнопки работают
  (звонить не обязательно).
- ✅ **Прошло:** экран открылся, не упал.

## 11. Завершение
- [ ] Заверши поездку.
- [ ] Уведомление в шторке исчезло (передача позиции остановилась).
- ✅ **Прошло:** поездка закрылась, уведомление ушло.
