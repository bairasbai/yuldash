# 🔤 Словарь башкирских терминов Юлдаша

> Решения принимает **Александр** — он носитель языка. Здесь они записаны,
> чтобы в следующий раз не выбирать заново и не разъезжаться между сайтом
> и приложением.
>
> **Правило:** этот файл сильнее любых других источников. Если приложение
> говорит одно, а словарь другое — прав словарь, приложение приводим к нему.

---

## Как пользоваться

**Пишешь новую надпись** — сначала загляни сюда. Слово из списка переводится
только так, других вариантов быть не должно.

**Нашёл разнобой** (одна русская фраза переведена на разных экранах по-разному) —
не выбирай сам. Выгрузи список в `webapp/BASHKIR_DRAFT.md` и спроси Александра.

**Появилось новое решение** — сразу сюда, в таблицу, с датой.

### Падежные формы «Йөрөтөүсе»

Слово оканчивается на гласную, поэтому аффиксы идут через `-н-` / `-л-`:

| Форма | Пример |
|---|---|
| именительный | Йөрөтөүсе |
| множественное | Йөрөтөүселәр |
| дательный (кому) | Йөрөтөүсегә |
| винительный (кого) | Йөрөтөүсене |
| родительный (чей) | Йөрөтөүсенең |
| исходный (от кого) | Йөрөтөүсенән |
| мн. винительный | Йөрөтөүселәрҙе |
| мн. дательный | Йөрөтөүселәргә |

⚠️ Частая ошибка: писать `водителгә`, `водителдәр` — это русский корень
с башкирскими окончаниями. Так было в 192 строках до 2026-08-14.

## Слова, которые НЕ переводим

Заимствования — в башкирском звучат так же. Пара `appText("Такси", "Такси")` тут
не ошибка, а норма:

`Такси` · `Комфорт` · `Эконом` · `Бизнес` · `Минивэн` · `Промокод` · `Телефон` ·
`Чат` · `Курьер` · `Реклама` · `Багаж` · `ОСАГО` · `СБП` · `Telegram` · `км` ·
`Юлдаш` · `Партнёр` · `Тариф` · `Транспорт` · `Код` · `Фото` · `Пауза`
(как слово-статус — но «Пауза» в смысле «остановлено» → `Туҡтатылған`)

## Как проверить, что словарь соблюдается

```bash
cd webapp && npm run check
```

Набор `glossary-test` проверяет автоматически, по обоим проектам сразу
(сайт + приложение, ~6400 надписей):

1. каждый термин из таблицы выше переводится ровно так, как решил Александр;
2. в башкирской половине нет русских корней (`водител` и подобных);
3. у каждой надписи есть вторая половина.

**Добавил решение в таблицу — добавь его и в проверку**: словарь продублирован
в `webapp/tests/glossary-test.mjs`, объект `GLOSSARY`. Тогда откат назад поймается
на первой же проверке, а не через полгода на экране у человека.

### Обёртка «предлог + значение» — не ошибка

Порядок слов в языках разный: по-русски предлог идёт ДО значения, по-башкирски
послелог — ПОСЛЕ. Поэтому фраза намеренно разбивается надвое:

```tsx
{appText("До ", "")}
{formatWhen(date, ru)}
{appText("", " ҡәҙәр")}
```

Обе половины на месте, просто в разных концах. Проверка это понимает и не ругается.
