## 🔴 P0 — проверить/сделать ДО запуска

### 1. Сервер: `ENV=prod` + случайный `JWT_SECRET` (server-side, за Александром)
Вся безопасность включается только при `ENV=prod` (`main.py:35` зовёт `validate_production()` лишь тогда). Если на `yulbash.ru` в `.env` не выставлен `ENV=prod`, сервер поднимется с дефолтным `JWT_SECRET="dev-secret-change-me"` → **любой подделает JWT за любого юзера** (захват аккаунтов) + открытый CORS + OTP в логах.
- **Проверить руками на сервере:** в `.env` есть `ENV=prod` (или `production`) и `JWT_SECRET` ≥16 случайных символов. Если сервер стартует без ошибки `validate_production` — значит `ENV=prod` уже стоит. (`.env` не в git — правильно; из репозитория не проверить.)

### 2. `seed_demo` — ✅ ПОЧИНЕНО (в этом заходе, PR #95)
Было: `seed_demo=True` по умолчанию и не блокировался в проде → риск фейковых демо-поездок в боевой БД. Стало: дефолт `False` + `validate_production()` отклоняет `SEED_DEMO=true` в проде. Тест `test_prod_config.py`.

## 🔴 UX-блокеры первого впечатления (нужна сборка Android)

> Общая причина 4 из 5: экран грузит серверные данные через `.onSuccess` **без `.onFailure` и без флага загрузки** → при обрыве сети показывает ложное «пусто» и вводит в заблуждение. **Главный рычаг: починить этот паттерн в 5 местах** (образец рядом — `PassengerCabinetContent` / `RidesScreen` / история чата — там сделано правильно).

1. **Кабинет водителя — нет loading/error** — `ProfileScreen.kt:838-849, 901-913, 941`. При сбое реальный водитель видит «маршрутов нет · Опубликовать» → публикует **дубли**.
2. **Активная поездка — опрос статуса без loading/error** — `BookingActiveTripScreen.kt:771-779`. При сбое пустой экран без «Повторить» (скрыты код посадки, кнопки статуса, live-баннер, оценка).
3. **Проверка водителя — статус без loading/error** — `SosVerifyScreens.kt:669-683`. При сбое видит «Проверка не пройдена» → **шлёт документы повторно**.
4. **Уведомления — 2 из 4 вкладок всегда пустые** — `SecondaryScreens.kt:269, 287-305`. Все уведомления с одной иконкой `ChatBubble`, вкладки фильтруют по иконке → «Поездки»/«Система» пусты. *Нужен `type` в DTO уведомлений (бэкенд+клиент) или убрать вырожденные вкладки.*
5. **Город захардкожен «Баймаҡ»** — `ProfileScreen.kt:480`, `BookingActiveTripScreen.kt:738`. Все видят «Пассажир · Баймаҡ». Читается как мок. *Реальный город из профиля (добавить в `/me`) или убрать ярлык на бету.*
