## 4. Найденные баги и фиксы

Все реальные, все починены и перепроверены на эмуляторе. Двуязычие соблюдено (`appText`).

### 🐞 Баг #1 — сырая ISO-дата на карточках поездок (3 места)
- **Где:** карточка поездки во вкладке «Поездки», экран активной поездки, активная бронь в профиле.
- **Симптом:** дата показывалась как `2026-07-03T12:44:19.838345` вместо `03.07, 12:44`.
- **Причина:** при сборке UI-модели `Ride` из `Booking` бралось `b.departAt` напрямую, без хелпера `formatDepart()` (который правильно применялся в других путях, напр. `RideDto.toUiRide()`).
- **Фикс:** `time = b.departAt.takeIf { it.isNotBlank() }?.let(::formatDepart) ?: …` в:
  - [RidesRequestsChatScreens.kt:376-377](../android/app/src/main/java/com/yuldash/app/RidesRequestsChatScreens.kt) (карточка + активная поездка через `displayRide`)
  - [ProfileScreen.kt:616](../android/app/src/main/java/com/yuldash/app/ProfileScreen.kt) (активная бронь в кабинете)
- **Проверка:** после фикса карточки показывают `23.06, 05:57` и `03.07, 12:44` (`27_fix_trip_date`).

### 🐞 Баг #2 — чеклист заявки лгал: всё зелёное, а кнопка неактивна
- **Где:** экран «Создать заявку», карточка «Проверка заявки».
- **Симптом:** чеклист показывал 3 зелёные галочки (маршрут, места, цена), но обязательное поле **«Дата и время»** в него не входило. Пользователь видит всё зелёным, тапает «Создать заявку» — а кнопка `disabled` (валидация `time.isNotBlank()`), без объяснения почему.
- **Причина:** `VoiceParsedCard` рисовал зелёную галочку у КАЖДОЙ строки безусловно; строки для даты/времени не было вовсе.
- **Фикс:** [AccessibilityScreens.kt](../android/app/src/main/java/com/yuldash/app/AccessibilityScreens.kt)
  - Добавлен `data class CheckLine(text, done)`; `VoiceParsedCard` теперь для `done=false` рисует серый `RadioButtonUnchecked` + приглушённый текст.
  - В чеклист добавлена явная строка «Дата и время не выбраны» (серая, пока не выбрано), остальные строки завязаны на реальную заполненность полей.
- **Проверка:** пустая форма → серый кружок + «Дата и время не выбраны», кнопка визуально серая (`28_fix_request_checklist`). Выбор даты в календаре → строка зеленеет, кнопка активна, сабмит создаёт заявку на сервере (req id=7) и ведёт в «Мои заявки» (`30`,`31`).

> Примечание: «мёртвый» `onClick = {}` в [BookingActiveTripScreen.kt:1037](../android/app/src/main/java/com/yuldash/app/BookingActiveTripScreen.kt) — **не баг**: это заглушка клика при `combinedClickable` с активным `onLongClick` (меню по долгому нажатию).
