# TF11: точечная проверка экрана итогов поездки на Android 11

QA-процесс предназначен для отдельного PR поверх #296. Он собирает неизменяемый
`af02351bebb3960919f021783022d87a0bf9e17d` и запускает на чистом эмуляторе Android
11 два Compose-класса. Это не общий Android CI и не изменение приложения.

- `TaxiDriverCompletedInstrumentedTest`: восемь тестов. Включает восстановление
  оценки пассажира без записи; потерянный ответ, проверка повторной отправки и
  сохранённое Compose-состояние покрыты у водителя.
- `TaxiPostTripInstrumentedTest`: два теста пассажирского экрана и чека.
- Для приёмки нужны все десять методами из фиксированного списка, без пропусков,
  повторов, обрыва runner или попыток выдать результат одного класса за оба.
- Пин debug API и запрет IPv4/IPv6 для пользовательских UID обоих APK действуют
  до инструментального запуска. Тесты используют синтетические обработчики,
  поэтому backend, учётные данные, `adb reverse` и реальные API не нужны.
  Публикуется только JSON с фиксированными именами тестов и результатом.
- Прогон не доказывает реальные запись/чтение backend, восстановление процесса,
  весь RU/BA × темы или готовность к выпуску. Maven/AVD-ошибка — не успешный тест.

Офлайн: `PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s tools/taxi_rating_emulator -p 'test_*.py'`.
Эти проверки проверяют классификацию результатов и порядок команд с подставным
ADB; работа самой матрицы Compose подтверждается только запуском на Android.
