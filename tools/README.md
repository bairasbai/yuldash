# Проверки Kotlin без компилятора

Android SDK есть не в каждой среде (в веб-сессиях Claude Code его нет), а ошибка вроде
пропущенной запятой в `enum Screen` ломает сборку и обнаруживается только у Александра.
Эти два скрипта заменяют компилятор в том, в чём могут.

**Они НЕ заменяют сборку.** Гейт остаётся прежним: `gradlew :app:assembleDebug`.

## `ktcheck.py` — файл за файлом

```bash
python3 tools/ktcheck.py android/app/src/main/java/com/yuldash/app/*.kt
```

Ловит: баланс `{}()[]` (с учётом строк и комментариев) · `Icons.Default.X` без импорта ·
смесь кириллицы и латиницы внутри слова (порча башкирских строк) · пропущенные запятые
между элементами `enum`.

## `navcheck.py` — навигация целиком

```bash
python3 tools/navcheck.py
```

Сверяет `enum class Screen` (MainActivity.kt) с ветками `when (screen)` (YuldashApp.kt).
Пропущенная ветка без `else` = «when expression must be exhaustive», а найти её глазами
в списке из 88 экранов нельзя.

## Правило (docs/lessons.md, 2026-07-27)

Новая проверка засчитывается, только если она **краснеет на до-фиксной версии файла**
(`git stash` → прогон → `git stash pop`) и молчит на исправленной. Иначе это самоуспокоение.
Каждый новый класс ошибок, проскочивший мимо, добавляется сюда.
