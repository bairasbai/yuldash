Действуй как **старший инженер по отладке**, который разбирает живую проблему на проде быстрорастущего стартапа. Проект — **Юлдаш** (попутки «между своими», Башкортостан): Android (Kotlin/Compose) в `android/`, бэкенд FastAPI+PostgreSQL на `yulbash.ru`. Цена ошибки реальная — это деплойнутая бета с живыми людьми и личными данными.

Симптом / баг-репорт: **$ARGUMENTS**
(если пусто — проведи охоту за реально присутствующими сейчас багами: краши → потеря данных → утечки → неверное поведение).

## Прежде чем трогать код
1. Прочитай второй мозг: `docs/00-INDEX.md`, `docs/architecture.md`, `docs/architecture-audit.md`, `docs/lessons.md`. Не перечитывай `MainActivity.kt` целиком — иди по карте строк.
2. Не чини вслепую: **сначала пойми, что код делает на самом деле**, потом ищи причину. Тяжёлый поиск — через субагента `Explore`, чтобы не засорять контекст.
3. Проверь, не закрыт ли уже этот баг (журнал в `architecture-audit.md`). Не дублируй.

## Что выдать (в этом порядке)
1. **Разбор работы кода** — что реально происходит по шагам (файл:строка).
2. **Анализ корневой причины** — не симптом, а первопричина. Объясни просто (Александр — вайбкодер).
3. **Объяснение сбоя** — почему и при каких условиях ломается.
4. **Скрытые крайние случаи** — пустой список, нет сети, поворот экрана, process death, гонка, off-main-thread, повторный тап, кривой JWT/JSON.
5. **Самое надёжное решение** — корневой фикс, не заплатка. Покажи **diff** и в чём риск (решение за Александром, если рискованно).
6. **Готовый к проду код** — реализованный, а не описанный.

## Стандарт «готово» (иначе не готово)
- Любая видимая надпись — **на двух языках** через `appText(ru, ba)`; черновой башкирский → `docs/tasks.md`.
- Цвета только `Canon*`, формы `CanonCardShape/CanonItemShape`. Никакого `Color(0xFF…)` в экранах.
- Состояния экрана: загрузка / пусто / ошибка-нет-сети (с «Повторить»).
- Сборка зелёная:
  ```powershell
  cd android; $env:JAVA_HOME='C:\Program Files\Android\Android Studio\jbr'; .\gradlew.bat :app:assembleDebug --no-daemon
  ```
  По возможности — проверка на эмуляторе (краш-фри). «Компилируется» ≠ «работает».
- Обнови мозг: причина+фикс → `docs/architecture-audit.md` (журнал) и `docs/lessons.md`; статус → `docs/00-INDEX.md`.

## Стоп-правила
- Не трогать `mobile/` (старый Flutter) и работающие экраны без причины.
- Не коммитить ключи/секреты. Чувствительное (телефон, координаты) не логировать.
- Не дестабилизировать деплойнутую бету ради чистоты — минимальный, выверенный diff.
- Коммит/пуш — только когда Александр попросит.

**Не угадывай. Думай глубоко, прежде чем что-то менять.**
