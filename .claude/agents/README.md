# 👥 Команда агентов Юлдаша

Специализированные суб-агенты Claude Code под разработку Юлдаша. Остальную работу основной агент делает сам, меняя роли (⭐ «Шляпы» в `AGENTS.md`, `docs/agent-roles.md`). Четыре узких агента (UI, архитектура, бэкенд, карты) удалены 13.10.2026: из-за битой шапки они ни разу не загружались, а их тексты устарели.

## Как звать
- **Сам** (принудительно): «через агента `yuldash-qa-verify` проверь экран X».
- **Авто:** Claude сам подберёт агента под задачу по полю `description`.
- **Параллельно** (изоляция): запускай нескольких через worktree (§12.C) — лид сводит и собирает **один раз**.

## Золотое правило параллели (§12)
**Один файл — один агент в один момент.** Экраны разнесены по своим файлам, но общие файлы (навигация `YuldashApp.kt`/`AppNav*.kt`, `MainActivity.kt`, `CanonTokens.kt`, `ApiClient.kt`, гиганты вроде `InstantOrderScreen.kt`) — если их правят двое, последний затирает первого. Параллелить безопасно только непересекающиеся зоны: экран ↔ экран ↔ `backend/` ↔ `docs/` ↔ `res/`. **Сборка одна и эмулятор один** — их держит один агент за раз (обычно `yuldash-qa-verify`).

## Пересечения (согласовывать)
- Контракты `data/*Socket.kt` ↔ `backend/`: форма сообщений синхронна с `docs/route-tracking-contract.md`.
- `security-privacy` — сквозной: подключается к любой зоне, где личные данные/ключи; замки §12 соблюдает.
