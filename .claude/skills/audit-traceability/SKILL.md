# Проверяемая приёмка режимов

Прочитай `docs/audit-rules.md` и [инструкцию](../../../docs/audit-traceability/README.md).
Статусы — только `docs/audit-blocks.md`. Выбирай режим по задаче, а не по содержимому кандидатного JSON:

- Попутка: `--mode rideshare`, W1-E2E-20261018, прежние семь must.
- Такси: `--mode taxi`, TAXI-E2E-20261023, десять обязательных групп B03/PATH-04/05.
- Доставка: `--mode courier`, COURIER-E2E-20261023, десять групп B04/PATH-06/07/08/09;
  отправитель, попутный перевозчик, профессиональный курьер и получатель.
- Общая приёмка приложения: `--all`. Новый режим сначала получает явный полный состав и профиль.

Из корня своего чекаута:

```powershell
python -B tools/audit_traceability/check.py --mode taxi --baseline-ref <полный-SHA-отдельно-проверенной-базы>
```

База — отдельно сверенный неизменяемый локальный Git-коммит со штатным составом каждого режима.
Кандидат одного режима: `--manifest test-results/<своя-папка>/taxi.json`.
Кандидаты всех режимов: `--all --manifest-dir test-results/<своя-папка>` с rideshare.json/taxi.json/courier.json.
Пути артефактов — от корня чекаута. Пропавший файл пакета даёт 2 без fallback; папка не меняет путь базы.

Код 0 — формальные условия выполнены, 1 — приёмка заблокирована, 2 — неверный ввод/окружение.
Для --all любой2 приоритетнее1; сохраняются все три результата. Возвращай настоящий код без `|| true`.
Первоначальные составы честно дают1: свежие цепочки ещё не связаны. Это не доказательство поломки функций.
Успех другого режима/общего теста не закрывает критерий автоматически. Все подусловия состава обязательны.
`accepted_with_skips` не означает полной приёмки. Строгая привязка HEAD не позволяет переименовать старый PASS.

Свежий принимающий проверяет первичные журналы, команду/код завершения, окружение, происхождение сборки,
зависимости и независимость проверки: JSON и хеши сами по себе не подтверждают подлинность/личность.
Телефоны, реальные внешние сервисы, BA носителем и выпуск остаются своими условиями каждого режима.
Сохрани различия: повтор оценки такси обновляет запись, второй голос доставки запрещён; расчёт/возврат/спор
и ссылки получателя не теряются за словом «курьер». Не добавляй выдуманный PASS и не меняй target старых журналов.
Итог/остатки — в существующий пункт реестра. Отчёт Александру: что доказано, что блокирует, следующий сценарий.
