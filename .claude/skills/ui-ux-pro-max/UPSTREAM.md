# Откуда взят этот скилл и как его обновлять

Это **чужой код**, скопированный в наш репозиторий (вендоринг). Он не наш — чинить баги
внутри него не надо, надо обновлять версию.

| Что | Значение |
|---|---|
| Источник | https://github.com/nextlevelbuilder/ui-ux-pro-max-skill |
| Версия | **2.13.0** |
| Лицензия | MIT |
| Скопировано | 2026-08-06 |
| Что именно взято | папка `.claude/skills/ui-ux-pro-max/` из того репозитория |

## Что НЕ взято и почему

В том репозитории лежат ещё 6 скиллов: `ui-styling` (5.8 МБ веб-шрифтов), `design-system`,
`design`, `brand`, `slides`, `banner-design`. Все они про веб-сайты, презентации и брендбуки —
для Android-приложения не нужны, поэтому не копировались. Если однажды понадобятся, взять
их из того же репозитория тем же способом.

## Наши правки поверх оригинала (2 штуки)

При обновлении версии их придётся нанести заново — оба в `SKILL.md`:

1. **Путь до скрипта.** В оригинале вызов идёт через `${CLAUDE_PLUGIN_ROOT}/...` — эта
   переменная существует, только если скилл поставлен как плагин. У нас он лежит прямо в
   репозитории, переменной нет, путь был бы битый. Убрали префикс: теперь
   `python ".claude/skills/ui-ux-pro-max/scripts/search.py"` от корня репозитория.
2. **Врезка про Юлдаш** в начале файла: стек всегда `jetpack-compose`, правила проекта
   (`Canon*`, двуязычие, `CanonSourceGuardTest`) важнее советов скилла, `--persist` не
   использовать.

## Как обновиться до новой версии

```bash
git clone --depth 1 https://github.com/nextlevelbuilder/ui-ux-pro-max-skill.git /tmp/uupm
rm -rf .claude/skills/ui-ux-pro-max
cp -r /tmp/uupm/.claude/skills/ui-ux-pro-max .claude/skills/
# нанести обе правки выше заново, вернуть этот файл (UPSTREAM.md) и обновить версию в таблице
```
