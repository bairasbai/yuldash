# UI Юлдаша — обязательные правила

Планка: экран должен выглядеть так, будто его сделала топовая студия. Спокойные цвета, воздух, выверенные отступы, iOS-плавность. **Красиво по умолчанию, без напоминаний.**

Полный справочник — [docs/design.md](../../../docs/design.md). Здесь — то, что нарушать нельзя.

---

## 1. Цвет — только `Canon*`

Хардкод `Color(0xFF…)` в экране **запрещён**. Нужного оттенка нет → заводи токен в `CanonTokens.kt`, не размазывай по экранам.

| Задача | Токен |
|---|---|
| Фон экрана | `CanonBg` |
| Карточка | `CanonSurface` + рамка `CanonBorder` |
| Основной текст | `CanonText` |
| Вторичный текст, подписи | `CanonMuted` |
| Основная кнопка | `CanonGreen2`, текст белый |
| Акцент бренда | `CanonGold`, текст `CanonGoldInk` |
| Мягкая подложка | `CanonMint` |
| Опасность, отмена, SOS | `CanonRed` / фон `CanonDangerBg` |
| Предупреждение, «в процессе» | `CanonWarn` / фон `CanonWarnBg` |
| Звёзды рейтинга | `CanonStar` |

**Три ловушки:**
- Шапка-градиент с белым текстом → **только** `CanonGreenInk` / `CanonGreenInkDark`. `CanonGreen`/`CanonGreen2` в тёмной теме становятся светлой мятой, белый текст пропадает.
- `CanonGreen2`, `CanonWarn`, `CanonRed` уже затемнены ради контраста. **Не осветлять обратно.**
- В `Canvas`/`DrawScope` нельзя звать `@Composable`-геттеры. Там работают только обычные `val`: `CanonStar`, `CanonGoldInk`, `CanonGreenInk`, `CanonHairlineGreen`, `CanonDangerBorder`.

## 2. Два языка — всегда

Каждая видимая надпись через `appText(ru, ba)`. **Односторонних строк не бывает** — включая `contentDescription` у иконок.

Башкирский от модели — черновик. Складывай в `docs/tasks.md`, раздел «Переводы на проверку». Александр носитель, он подтвердит.

Башкирский обычно длиннее русского — вёрстка не должна ломаться.

⚠️ `appText()` и любой `@Composable` **нельзя звать внутри тела `LazyColumn`** — не соберётся. Списки строк готовь выше, в теле функции.

## 3. Все состояния, не только «успех»

Экран без загрузки / пусто / ошибки — **не готов**.

Бери `AppStateContainer` из `UiKit.kt` — он сам выбирает, что показать. Для списков предпочитай `SkeletonCard` спиннеру.

- **Не показывать спиннер поверх уже загруженных данных.** Контейнер уходит в загрузку только при пустом списке.
- Пусто → дружелюбная заглушка, а не демо-данные. Фейк показывать можно только при офлайне, не при пустом успехе.
- 401 (не вошёл) ≠ нет сети. Не писать «проверь интернет» тому, кто просто не залогинен.
- Ошибка — спокойно и с выходом: «Не получилось загрузить. Повторить?» Без обвинения пользователя.

## 4. Готовые компоненты — не изобретать

Всё в `UiKit.kt`: `AppButton`, `AppCard`, `SectionHeader`, `AppStateContainer`, `AppLoading`, `AppErrorState`, `AppEmptyState`, `SkeletonBox`, `SkeletonCard`.

Кнопка с сетевым запросом — всегда через `loading=`, не блокируй экран целиком.

## 5. Шкалы — своих значений не заводить

Замер 2026-08-04: до сведения в приложении жило **27 кеглей, 70 отступов, 18 радиусов,
38 длительностей**. Одно и то же по роли выглядело по-разному на каждом экране — это
и читалось как «самоделка». Теперь одна шкала на всё, и её держит `CanonSourceGuardTest`:
он читает исходники и **падает на любом своём значении**.

**Кегль — токеном, а не числом.** Пиши `style = CanonBody`, не `fontSize = 16.sp`.

| Токен | Роль |
|---|---|
| `CanonDisplay` 34 | Крупное число: цена, баланс, км. И заголовок онбординга |
| `CanonTitle` 24 | **Заголовок экрана.** Один на экран |
| `CanonHeading` 19 | Заголовок блока/карточки |
| `CanonBody` 16 **Normal** | Основной текст |
| `CanonBodyStrong` 16 | Акцент в строке: имя, город, цена |
| `CanonCaption` 14 | Вторичный текст |
| `CanonMicro` 12 | Метки, бейджи |
| `CanonButton` 16 | Надпись на кнопке |

**Основной текст НЕ жирный.** Было 1008 жирных из 1067 — когда выделено всё, не выделено
ничто. `FontWeight.Black` **запрещён** (убран из 59 файлов, держится тестом).

| Ось | Ступени |
|---|---|
| Отступ (воздух) | `CanonSpace` xs 4 · sm 8 · md 12 · **lg 16 (карточка и поле экрана)** · xl 24 · xxl 32 · huge 48 |
| Радиус | `CanonCardShape` 28 · `CanonItemShape` 22 · `CanonFieldShape` 14 · `CanonTinyShape` 8 · `RoundedCornerShape(999.dp)` — пилюля |
| Тень | `CanonDepth` flat 0 · **card 1 (по умолчанию)** · raised 4 (плавает над контентом) · sheet 12 (шторка) |
| Движение | `CanonMotion` — 11 ступеней: QUICK 180 · NORMAL 260 · SLOW 320 · ENTRY 500 · COUNT 700 · SCENE 820 · TICK 1000 · PULSE 1100 · CINEMA 1600 · DRIFT 4700 · AMBIENT 9000 |

Лестница отступов — про **воздух** (`padding`, `spacedBy`, `Spacer`). Геометрия (высота
карточки, размер иконки) задаётся по месту.

⚠️ **`padding` вокруг кликабельного часто И ЕСТЬ зона нажатия.** Уменьшил отступ — уменьшил
кнопку ниже 48dp.

## 6. Анимации

| Что | Значение |
|---|---|
| Отклик на нажатие | `bounceClick` — scale 0.97, `CanonMotion.QUICK` |
| Появление карточки | `appearIn(index)` — alpha 0→1 + сдвиг 40→0, `CanonMotion.SLOW` |
| Каскад списка | `CanonMotion.cascadeIn(index)` — 40 мс на соседа, с потолком |
| Пульс ожидания | `canonBreath(label, from, to, rest)` — темп `CanonMotion.PULSE` |
| Фоновый дрейф | `canonDrift(label)` — темп `CanonMotion.AMBIENT` |

Как выбирать ступень: `ENTRY` — приход одного элемента (бейдж, печать, баннер), `COUNT` —
докрутка числа или полоски, `SCENE` — проявление картины во весь экран, `PULSE` — «дыхание»
ожидания, `TICK` — дотяжка под секундный таймер, `CINEMA`/`DRIFT`/`AMBIENT` — заставка и фон.

Своё число писать нельзя **нигде**: и `tween(200)`, и спрятанное за переменной
`delayMillis = index * 55` уронят сторожа. Шкала действует и на таймерах, и на бесконечных
циклах — заводить `infiniteRepeatable` руками сторож тоже не даст.

⚠️ **`appearIn` в `LazyColumn` требует `key` у item.** Без ключа элемент пересоздаётся,
анимация стартует заново и **залипает на прозрачности 0** — блок просто не виден. Уже ловили.

⚠️ Тяжёлый `Canvas` с перерисовкой каждый кадр блокирует главный поток и ломает саму анимацию. Проверять `adb logcat | grep "Skipped .* frames"`.

## 7. Доступность и адаптив

- Тач-цель ≥ 48dp (у `AppButton` фактически 54dp).
- Текст только в `sp`. Контраст ≥ 4.5:1, белый на цветной кнопке ≥ 3:1.
- Системные вырезы — `statusBarsPadding()` / `navigationBarsPadding()` / `safeDrawing`. Контент не лезет под статус-бар.
- Поле ввода не должно прятаться за клавиатурой — `imePadding()`.
- Списки — `LazyColumn`/`LazyRow` с `key`. Тяжёлое — в `remember`.

## 8. Новый экран

1. Ветка в `enum Screen` (`MainActivity.kt`)
2. Ветка в `when(screen)` внутри `YuldashApp()`
3. Строка в `docs/architecture.md`
4. Навигация — через `YuldashViewModel` (состояние вверх, переживает поворот)

**Экран-ВКЛАДКА гасит свои инсеты.** Вкладки живут внутри общего `Scaffold` в `YuldashApp`,
он уже отдал отступ под статус-бар. Свой `Scaffold` без этого добавит его второй раз, и
заголовок уедет ниже, чем у соседних вкладок:

```kotlin
Scaffold(containerColor = CanonBg, contentWindowInsets = WindowInsets(0, 0, 0, 0)) { padding -> … }
```

Отдельный экран (открывается поверх) — наоборот, инсеты нужны: `Scaffold(topBar = { ScreenTopBar(…) })`.

Поле по бокам у всех вкладок — **16dp** (`CanonSpace.lg`).

**Карта** — только через `ensureMapKit(context)` (`MapScreen.kt`). Голый
`MapKitFactory.initialize()` в экране запрещён: локаль процессная, и логотип станет
русским или английским в зависимости от того, какую карту открыли первой.

## Чеклист перед «готово»

Не помечать сделанным, пока все семь не да:

- [ ] Каждая надпись двуязычная, черновой башкирский выписан в `tasks.md`
- [ ] Ни одного `Color(0xFF…)`, своего кегля, радиуса, длительности или тени
- [ ] Есть загрузка, пусто и ошибка — не только успех
- [ ] Анимация появления и отклик на нажатие есть, у `item` есть `key`
- [ ] Контент не лезет под статус-бар и клавиатуру
- [ ] `gradlew :app:assembleDebug` — зелёный
- [ ] `CanonSourceGuardTest` — зелёный
- [ ] **Глазами на эмуляторе: 4 комбинации — светлая/тёмная × русский/башкирский**

Последний пункт нельзя заменить ничем. Восемь дефектов полировки не поймали ни компилятор,
ни 1174 теста: обрезанная карточка, невидимый блок ленты, белая карта в тёмной теме,
заголовки вкладок на разной высоте, закрытый логотип Яндекса, обрезанный башкирский.

Башкирский длиннее русского: любая тесная строка (несколько надписей в ряд, `maxLines = 1`)
проверяется на нём **отдельно**. «отправить посылку» влезало, «бандероль ебәреү» — нет.

## Оркестрация (§12 CLAUDE.md)

`MainActivity.kt` — общий файл, последняя запись затирает чужую. Правишь его — ты единственный UI-агент в этот момент. Разные `*Screen.kt` можно вести параллельно. Перед стартом перечитай `docs/tasks.md` — раздел «Замки».

Сборка и эмулятор — **один агент за раз**.
