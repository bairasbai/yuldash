# 🧰 Скиллы Юлдаша

Скилл — это инструкция, которую Claude подгружает сам, когда задача под неё подходит.
Лежат прямо в репозитории, поэтому работают одинаково на машине Александра, в облачной
сессии и у любого суб-агента. Ростер суб-агентов — [.claude/agents/README.md](../agents/README.md).

## Наши (написаны под Юлдаш)

| Скилл | Когда включается | Что делает |
|---|---|---|
| **`yuldash-ui`** | автоматически при любой работе с интерфейсом | выжимка дизайн-системы: `Canon*`, двуязычие, состояния экрана, анимации |
| **`orchestration`** | когда задача режется на параллельные куски | зоны ответственности, очередь на сборку, «замок» на файл, worktree |
| **`gotovo`** | перед словом «готово» или по `/gotovo` | по изменённым частям запускает проверки как в CI и отдаёт таблицу с выводом |
| **`audit-traceability`** | при приёмке попутки W1-E2E или по `/audit-traceability` | связывает требования, реализации, реальные прогоны и независимую приёмку; показывает недостающие доказательства |

Рядом — автоматика в `.claude/settings.json`: после каждой правки хук
`.claude/hooks/yuldash-post-edit.mjs` ловит мёртвые импорты в бэкенде (ruff, как CI),
захардкоженный `Color(0x…)` и одноязычный `Text("…")` в экранах; правки в `mobile/` и чтение
ключей (`local.properties`, `google-services.json`, keystore) запрещены в любой папке, а хук
`.claude/hooks/yuldash-secrets-guard.mjs` — сетка от случайного чтения: не даёт команде терминала прочитать,
скопировать или упаковать их (по имени, маске, конвейеру, рекурсивному поиску). Не стена; граница — запрет Read и классификатор.
Таблица случаев — `yuldash-secrets-guard.test.mjs` рядом.

## Чужие (скопированы из открытых репозиториев)

Это **вендоринг** — копия чужого кода внутрь нашего репозитория. Плюс: работает офлайн,
версия зафиксирована, доступна всем агентам. Минус: обновлять руками.

### Допрос перед кодом

| Скилл | Откуда | Лицензия |
|---|---|---|
| **`grill-me`** + **`grilling`** | [mattpocock/skills](https://github.com/mattpocock/skills) | MIT |

Режим «сначала допроси, потом пиши код». Взяты **без правок**.

- **Сам не включается.** В `grill-me` стоит `disable-model-invocation: true` — запустить
  может только Александр, написав `/grill-me`.
- **Отменяет автопилот на время сессии.** Обычное правило `CLAUDE.md` ⭐ — «не задавать
  вопросов, делать самому». `/grill-me` — осознанное исключение, оно записано в `CLAUDE.md` ⭐.
- **`grilling`** — движок, `grill-me` его зовёт. Поодиночке не работают, поэтому парой.
- Вопросы задаём по-русски и как школьнику (`CLAUDE.md` §2), хотя скилл английский.

### Дизайн и анимации (набор Эмиля Ковальски)

| Скилл | Про что | Сам включается? |
|---|---|---|
| **`apple-design`** | принципы Apple: пружины, перехват жеста, инерция, материалы, типографика, 8 принципов дизайна | да |
| **`emil-design-eng`** | философия полировки UI + формат разбора «было / стало / почему» | да |
| **`emil-animate`** | строит анимацию с нуля: нужна ли вообще, чем, какая кривая, длительность, как прерывается. У Эмиля называется `animate` — переименован, потому что глобальный `animate` (impeccable) с тем же именем перекрывал наш: личные скиллы важнее проектных | да |
| **`find-animation-opportunities`** | ищет места, где движения не хватает — и где оно вредно | да |
| **`improve-animations`** | аудит всех анимаций проекта + план правок для других агентов | да |
| **`animation-vocabulary`** | словарь: описание эффекта словами → его точное название | да |
| **`review-animations`** | строгая проверка уже написанных анимаций | только `/review-animations` |
| **`pick-ui-library`** | подбор готовых библиотек | только `/pick-ui-library` |
| **`prototype`** | несколько вариантов экрана сразу, с переключателем | только `/prototype` |

Откуда: [emilkowalski/skills](https://github.com/emilkowalski/skills), лицензия MIT,
скопировано 2026-08-06.

**Наша правка — врезка в начале `SKILL.md`,** у восьми из девяти (не тронут только
`animation-vocabulary` — это чистый словарь):

- шести «про интерфейс» (`apple-design`, `emil-design-eng`, `emil-animate`,
  `find-animation-opportunities`, `improve-animations`, `review-animations`) — напоминание,
  что мы пишем Compose, а не веб: **принцип и число брать можно, код — нет**; длительности
  со шкалы `CanonMotion` (иначе падает `CanonSourceGuardTest`), цвета `Canon*` (иначе `ColorSourceGuardTest`);
- двум «про веб» (`pick-ui-library`, `prototype`) — что они применимы к лендингу в `web/`,
  а не к приложению в `android/`.

Обновление: скопировать папки заново и нанести врезки повторно.

```bash
git clone --depth 1 https://github.com/emilkowalski/skills.git /tmp/emil
cp -r /tmp/emil/skills/* .claude/skills/
# их animate у нас живёт как emil-animate (глобальный animate его перекрывает):
rm -rf .claude/skills/emil-animate && mv .claude/skills/animate .claude/skills/emil-animate
sed -i 's/^name: animate$/name: emil-animate/' .claude/skills/emil-animate/SKILL.md
```

После копирования заново нанеси врезки «правила Юлдаша важнее» (см. ниже) — копия их стирает.

## Правило для любого чужого скилла

Правила проекта важнее его советов. Чужой скилл не знает про шкалы `Canon*`, двуязычие
`appText(ru, ba)` и `CanonSourceGuardTest` — берёшь совет, сверяй с
[docs/design.md](../../docs/design.md). И перед тем как класть новый чужой скилл в
репозиторий — **прочитай его**: скрипты, сеть, запуск команд, запись и удаление файлов.
