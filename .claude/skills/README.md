# 🧰 Скиллы Юлдаша

Скилл — это инструкция, которую Claude подгружает сам, когда задача под неё подходит.
Лежат прямо в репозитории, поэтому работают одинаково на машине Александра, в облачной
сессии и у любого суб-агента. Ростер суб-агентов — [.claude/agents/README.md](../agents/README.md).

## Наши (написаны под Юлдаш)

| Скилл | Когда включается | Что делает |
|---|---|---|
| **`yuldash-ui`** | автоматически при любой работе с интерфейсом | выжимка дизайн-системы: `Canon*`, двуязычие, состояния экрана, анимации |
| **`orchestration`** | когда задача режется на параллельные куски | зоны ответственности, очередь на сборку, «замок» на файл, worktree |

## Чужие (скопированы из открытых репозиториев)

Это **вендоринг** — копия чужого кода внутрь нашего репозитория. Плюс: работает офлайн,
версия зафиксирована, доступна всем агентам. Минус: обновлять руками.

| Скилл | Откуда | Версия | Лицензия | Зачем нам |
|---|---|---|---|---|
| **`ui-ux-pro-max`** | [nextlevelbuilder/ui-ux-pro-max-skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) | 2.13.0 | MIT | база из 98 UX-правил, палитр, типографики и гайдлайнов Jetpack Compose с поиском |
| **`grill-me`** + **`grilling`** | [mattpocock/skills](https://github.com/mattpocock/skills) | 2026-08-06 | MIT | режим «сначала допроси, потом пиши код» — включает **только Александр** командой `/grill-me` |

Подробности по `ui-ux-pro-max` (что поправлено, как обновиться) — в
[ui-ux-pro-max/UPSTREAM.md](ui-ux-pro-max/UPSTREAM.md). Оба скилла Мэтта Пококка взяты
**без правок**, обновление = скопировать папки заново:

```bash
git clone --depth 1 https://github.com/mattpocock/skills.git /tmp/mp
cp -r /tmp/mp/skills/productivity/grill-me /tmp/mp/skills/productivity/grilling .claude/skills/
```

### Про `grill-me` — важное

- **Сам не включается.** В нём стоит `disable-model-invocation: true` — запустить может
  только Александр, написав `/grill-me`. Агент по своей инициативе в этот режим не уходит.
- **Отменяет автопилот на время сессии.** Обычное правило `CLAUDE.md` ⭐ — «не задавать
  вопросов, делать самому». `/grill-me` — осознанное исключение: вопросы раундами, код
  только после подтверждения. Это записано в `CLAUDE.md` ⭐.
- **Вопросы задаём по-русски и как школьнику** (`CLAUDE.md` §2), хотя сам скилл написан
  по-английски. Правила проекта важнее формулировок чужого скилла.
- **`grilling`** — это движок, `grill-me` его просто зовёт. Поодиночке они не работают,
  поэтому лежат парой.

## Правило для любого чужого скилла

Правила проекта важнее его советов. Чужой скилл не знает про шкалы `Canon*`, двуязычие
`appText(ru, ba)` и `CanonSourceGuardTest` — берёшь совет, сверяй с
[docs/design.md](../../docs/design.md). И перед тем как класть новый чужой скилл в
репозиторий — **прочитай его скрипты**: сеть, запуск команд, запись и удаление файлов.
