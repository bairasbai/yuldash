# Архив ручных SQL-миграций (историческое)

Эти `migrate_*.sql` применялись вручную (`psql -f`) ДО перехода на alembic как единый
источник истины по схеме БД (WP-2 аудита 2026-07-04).

**Больше не использовать.** Актуальные миграции — в `backend/alembic/versions/`.
Схема меняется только через:
```
alembic revision -m "описание"   # создать ревизию (обычно autogenerate/ручная, идемпотентная)
alembic upgrade head             # применить (деплой делает это сам, см. deploy-backend.bat)
```

Файлы оставлены для истории (что и когда добавлялось в схему на раннем этапе). Их эффекты
уже отражены в baseline `0001` (create_all из моделей) и последующих ревизиях.
